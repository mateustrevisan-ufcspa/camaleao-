# US-38 · Comissão nas vendas, com quem captou (5 SP)

> Como coordenadora do financeiro, eu quero marcar em cada venda se teve comissão e para quem, com o mesmo percentual das doações, para que a comissão paga no mês inclua o que foi captado no brechó.

**Tipo:** user story · **Implementa:** Bibiana · **Revisa:** Mateus · **Branch:** `us-38-comissao-nas-vendas` · **Depende de:** US-31 (na `main` desde 12/11) e US-04b (venda cancelada some, integrada na terça) · **PR pronto:** quarta 18/11, 18h · **Merge:** quarta 18/11, à noite

**Origem:** resposta 7 da Nílian (09/11): comissão de vendas **e** de doações, 25% sobre o líquido, percentual ajustável, marcar quando teve e quando não teve, paga todo mês. Decisão de 09/11: a US-31 ficou com as doações; esta story faz as vendas, no mesmo desenho.

## Critérios de aceitação

- [ ] Em Relatórios · Comissões, as vendas do mês aparecem numa segunda tabela, com a mesma marcação das doações: quem captou ou "Sem comissão"
- [ ] A comissão da venda é calculada pelo banco sobre o líquido da venda, com o **mesmo percentual** em vigor das doações (US-31), gravado na marcação
- [ ] "Comissão do mês", "Por quem captou", "a marcar" e "Marcadas para somar" juntam doações e vendas
- [ ] Venda cancelada (US-04b) some da tabela e da soma
- [ ] O relatório consolidado e a planilha exportada incluem as comissões das vendas (aba "Comissões das vendas")
- [ ] Só a coordenação marca, corrige e desmarca; correção e desmarcação entram em Relatórios · Alterações
- [ ] Testes de acesso e de fumaça passam

## Decisões

- **Tabela irmã, e não `sale_id` na tabela da US-31:** `comissoes_de_venda`, com as mesmas colunas e regras de `comissoes_de_doacao`. Assim nenhuma linha da US-31 muda, e o `unique (sale_id)` fica simples.
- **Mesmo gatilho de carimbo:** `carimbar_comissao()` (US-31) não olha a tabela, só `percentual`, `definido_em` e `definido_por`. Serve às duas.
- **Mesmo percentual:** a tabela `percentual_de_comissao` continua uma só. Alterar vale para as próximas marcações de doações e vendas.
- **Líquido da venda:** `sales.net_amount`, como no financeiro. Venda em dinheiro tem líquido igual ao valor.

```sql
-- US-38 · Comissão nas vendas, com quem captou
-- O mesmo desenho da US-31: uma marcação por venda (teve ou não comissão, para
-- quem), o percentual em vigor gravado na marcação e o valor calculado sobre o
-- líquido. Só a coordenação.

create table public.comissoes_de_venda (
  id            uuid primary key default gen_random_uuid(),
  sale_id       uuid not null unique references public.sales(id) on delete cascade,
  teve_comissao boolean not null,
  captador_id   uuid references public.captadores(id) on delete restrict,
  percentual    numeric(5,2) check (percentual >= 0 and percentual <= 100),
  definido_em   timestamptz not null default now(),
  definido_por  uuid references public.users(id) on delete set null,
  constraint comissao_da_venda_com_quem_captou check (
    (teve_comissao and captador_id is not null) or (not teve_comissao and captador_id is null)
  )
);

create index idx_comissoes_de_venda_captador on public.comissoes_de_venda (captador_id);

-- Quem, quando e o percentual vêm do banco (a mesma função da US-31).
-- "carimbo" vem antes de "trilha" na ordem alfabética.
create trigger carimbo_da_comissao
  before insert or update on public.comissoes_de_venda
  for each row execute function public.carimbar_comissao();

create trigger trilha_de_auditoria before update or delete on public.comissoes_de_venda
  for each row execute function public.registrar_na_trilha();

alter table public.comissoes_de_venda enable row level security;

create policy "coordenacao le" on public.comissoes_de_venda
  for select to authenticated using (public.eh_coordenacao());
create policy "coordenacao marca" on public.comissoes_de_venda
  for insert to authenticated with check (public.eh_coordenacao());
create policy "coordenacao corrige" on public.comissoes_de_venda
  for update to authenticated using (public.eh_coordenacao()) with check (public.eh_coordenacao());
create policy "coordenacao desmarca" on public.comissoes_de_venda
  for delete to authenticated using (public.eh_coordenacao());

revoke all on public.comissoes_de_venda from anon;
grant select, insert, update, delete on public.comissoes_de_venda to authenticated;

-- Marcações com a venda, quem captou e o valor sobre o líquido. security_invoker:
-- só a coordenação recebe linhas, e a venda cancelada (US-04b) não aparece.
create view public.comissoes_de_venda_view
with (security_invoker = true) as
select
  k.id,
  k.sale_id,
  k.teve_comissao,
  k.captador_id,
  c.nome as captador_nome,
  k.percentual,
  case
    when k.teve_comissao and s.net_amount is not null and k.percentual is not null
      then round(s.net_amount * k.percentual / 100, 2)
  end as valor,
  k.definido_em,
  s.sold_at,
  s.customer_name,
  -- sales não tem coluna amount: o valor da venda é a soma dos itens (como na sales_view).
  coalesce((select sum(si.amount) from public.sale_items si where si.sale_id = s.id), 0) as amount,
  s.net_amount
from public.comissoes_de_venda k
left join public.captadores c on c.id = k.captador_id
join public.sales s on s.id = k.sale_id;

revoke all on public.comissoes_de_venda_view from anon;
grant select on public.comissoes_de_venda_view to authenticated;
```

Conferido em 15/11: `sales` tem `customer_name`, `net_amount` e `sold_at`, mas **não tem `amount`**. O `amount` que `COLUNAS_VENDA` lê vem da `sales_view`, que soma `sale_items.amount`; a view acima faz a mesma soma.

export async function getVendasComComissao(ano: number, mes: number): Promise<VendaComComissao[]> {
  const desde = brMidnightUtc(ano, mes, 1).toISOString()
  const ate = (mes === 12 ? brMidnightUtc(ano + 1, 1, 1) : brMidnightUtc(ano, mes + 1, 1)).toISOString()
  const supabase = await createClient()
  const [vendas, comissoes] = await Promise.all([
    supabase.from('sales_view').select('id, sold_at, customer_name, amount, net_amount').gte('sold_at', desde).lt('sold_at', ate).order('sold_at'),
    supabase.from('comissoes_de_venda_view').select('sale_id, teve_comissao, captador_id, captador_nome, percentual, valor').gte('sold_at', desde).lt('sold_at', ate),
  ])
  const erro = vendas.error ?? comissoes.error
  if (erro) throw new Error(erro.message)
  const porVenda = new Map((comissoes.data ?? []).map((k) => [k.sale_id as string, k]))
  return (vendas.data ?? []).map((v) => {
    const k = porVenda.get(v.id as string)
    return {
      id: v.id as string,
      sold_at: v.sold_at as string,
      customer_name: (v.customer_name as string) || 'Sem nome',
      amount: Number(v.amount),
      net_amount: v.net_amount === null ? null : Number(v.net_amount),
      marcacao: !k ? 'a_marcar' : k.teve_comissao ? 'com' : 'sem',
      captador_id: (k?.captador_id as string | null) ?? null,
      captador_nome: (k?.captador_nome as string | null) ?? null,
      percentual: k?.percentual == null ? null : Number(k.percentual),
      comissao: k?.valor == null ? null : Number(k.valor),
    }
  })
}
