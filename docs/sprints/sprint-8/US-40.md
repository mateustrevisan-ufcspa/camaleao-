# US-40 · Recibo com razão social, CNPJ, assinatura e logo (2 SP)

> Como coordenadora do Instituto, eu quero que o recibo de doação traga a razão social, o CNPJ, a logo e a assinatura da presidente, para que o apoiador receba um comprovante oficial do Instituto.

**Tipo:** user story · **Implementa:** Mateus · **Revisa:** Laís · **Branch:** `us-40-dados-do-instituto-no-recibo` · **Depende de:** US-16 (na `main` desde 05/11) · **PR pronto:** segunda 16/11, 18h · **Merge:** segunda 16/11, à noite (sem migração)

**Origem:** resposta 12 (Flávia, 06/11): razão social INSTITUTO CAMALEÃO; CNPJ 25.535.215/0001-38; assina Flávia Maoli Magalhães de Oliveira, presidente; com a logo do Camaleão; sem dedução de imposto de renda por enquanto. Endereço não informado. Era pendência da Sprint 7 ("Recibo com CNPJ, assinatura e logo").

## Critérios de aceitação

- [ ] O recibo mostra a logo, a razão social "INSTITUTO CAMALEÃO" e "CNPJ 25.535.215/0001-38" no cabeçalho
- [ ] No fim, a linha de assinatura com "Flávia Maoli Magalhães de Oliveira" e, abaixo, "Presidente"
- [ ] Sem endereço (não informado) e sem nenhuma frase sobre imposto de renda
- [ ] O texto corrido continua dizendo "O Instituto Camaleão recebeu de..." (nome de uso, e não a razão social em maiúsculas)
- [ ] A impressão e o "Salvar em PDF" saem numa página, com a logo
- [ ] Testes de fumaça e de acesso passam

## Decisões

- **Os dados ficam em `lib/instituto.ts`**, como a US-16 previu. São dados públicos do Instituto (CNPJ e nome da presidente aparecem em qualquer recibo), então podem ficar no código.
- **Razão social e nome de uso separados:** `razaoSocial` no cabeçalho; `nome` no texto e no rodapé.
- **Imposto de renda:** a Flávia disse "sem dedução por enquanto". O recibo não fala do assunto: nem promete dedução, nem nega. Se o Instituto quiser uma frase, é um campo a mais aqui.

## Parte A · `lib/instituto.ts`

```ts
// US-16 e US-40 · Dados do Instituto que vão no recibo (resposta 12 da Flávia, 06/11).
// Campo null não aparece no recibo.
export const INSTITUTO = {
  // Nome de uso, no texto do recibo e no rodapé.
  nome: 'Instituto Camaleão',
  // Como está no CNPJ, no cabeçalho.
  razaoSocial: 'INSTITUTO CAMALEÃO',
  cnpj: '25.535.215/0001-38' as string | null,
  // Não informado pelo Instituto até 15/11.
  endereco: null as string | null,
  logo: '/logo-camaleao.png',
  assinatura: {
    nome: 'Flávia Maoli Magalhães de Oliveira',
    cargo: 'Presidente',
  } as { nome: string; cargo: string } | null,
}
```

Procure outros usos antes de trocar o tipo de `assinatura`: `grep -rn "INSTITUTO\." app components lib`. Hoje só o recibo usa.

## Parte B · `app/recibo/[tipo]/[id]/page.tsx`

1. Import: `import Image from 'next/image'`.
2. O `<header>` passa a ser:

```tsx
        <header className="border-b border-rule pb-6 mb-6 flex items-center gap-5">
          <Image src={INSTITUTO.logo} alt="Logo do Instituto Camaleão" width={210} height={151} className="w-[96px] h-auto" priority />
          <div>
            <div data-testid="razao-social" className="font-display text-2xl font-semibold">{INSTITUTO.razaoSocial}</div>
            {INSTITUTO.cnpj && <div className="text-sm text-muted mt-1">CNPJ {INSTITUTO.cnpj}</div>}
            {INSTITUTO.endereco && <div className="text-sm text-muted">{INSTITUTO.endereco}</div>}
          </div>
        </header>
```

3. A assinatura:

```tsx
        {INSTITUTO.assinatura && (
          <div data-testid="assinatura" className="mt-16 w-[320px] border-t border-ink pt-2 text-sm">
            <div>{INSTITUTO.assinatura.nome}</div>
            <div className="text-muted">{INSTITUTO.assinatura.cargo}</div>
          </div>
        )}
```

O resto da página não muda. O `proxy.ts` já deixa passar `.png` sem sessão (matcher), então a logo carrega no recibo e na impressão.

## Parte C · Teste

`tests/fumaca/recibo.spec.ts`, no primeiro teste, depois de `await expect(recibo).toContainText('Instituto Camaleão')`:

```ts
    // US-40 · Dados do Instituto (resposta 12).
    await expect(recibo.getByTestId('razao-social')).toHaveText('INSTITUTO CAMALEÃO')
    await expect(recibo).toContainText('CNPJ 25.535.215/0001-38')
    await expect(recibo.getByRole('img', { name: 'Logo do Instituto Camaleão' })).toBeVisible()
    await expect(recibo.getByTestId('assinatura')).toContainText('Flávia Maoli Magalhães de Oliveira')
    await expect(recibo.getByTestId('assinatura')).toContainText('Presidente')
    await expect(recibo).not.toContainText('imposto de renda')
```
