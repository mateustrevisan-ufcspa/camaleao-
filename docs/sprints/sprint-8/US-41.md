# US-41 · Agradecimento semanal e anual (8 SP)

> Como coordenadora do Instituto, eu quero agradecer toda semana quem trouxe item na sede e, no fim do ano, agradecer cada apoiador por tudo o que fez no ano, para que o reconhecimento siga o jeito que o Instituto já agradece hoje.

**Tipo:** user story · **Implementa:** Mateus · **Revisa:** Alissa · **Branch:** `us-41-agradecimento-semanal-e-anual` · **Depende de:** US-39 (funções `pessoas_para_agradecer`, `registrar_agradecimento` e `intervalo_do_periodo`, integrada na quinta 19/11) · **PR pronto:** segunda 23/11, 18h · **Merge:** segunda 23/11, à noite (último merge de story nova antes do treinamento)

**Origem:** resposta 2 da Flávia (06/11), que ficou como "ponto a decidir" na Sprint 7. Três agradecimentos:

- **Mensal**, até o dia 10, para quem **doou dinheiro ou comprou no brechó** no mês anterior, com o número de atendimentos (1 a cada R$ 50).
- **Semanal**, para quem **trouxe item na sede** (tampinhas, roupas etc.), com uma mensagem padrão, sem dizer o quê.
- **Anual**, no fim do ano, com tudo do ano: atendimentos para quem comprou ou doou dinheiro, e um texto fixo para quem só doou item.

Decisão do Mateus em 15/11: entra na Sprint 8, com ele.

## Critérios de aceitação

- [ ] Clientes · Agradecimentos com três abas: **Mensal**, **Semanal** e **Anual**, cada uma com a navegação do período (anterior e seguinte)
- [ ] Mensal: só quem comprou ou doou dinheiro no mês; a mensagem traz o valor e os atendimentos e **não fala de peças**. A aba abre no **mês anterior**, com o lembrete "envie até o dia 10"
- [ ] Semanal: só quem doou item na semana (segunda a domingo); mensagem padrão, sem dizer o que doou. Abre na **semana anterior**
- [ ] Anual: todo mundo que contribuiu no ano; quem comprou ou doou dinheiro recebe o total e os atendimentos do ano; quem só doou item recebe o texto fixo. Abre no ano atual
- [ ] Um agradecimento por pessoa em cada período: uma vez por semana, uma por mês e uma por ano, independentes
- [ ] O banco recusa agradecer na semana quem não doou item na semana, e no mês quem não comprou nem doou dinheiro no mês
- [ ] Caixa e coordenação usam as três abas (US-39); os textos são propostos pela equipe, e o Instituto pode pedir troca
- [ ] Testes de acesso e de fumaça passam

## Decisões

- **Período em texto, como na US-21a:** `AAAA-MM` (mês), `AAAA-Snn` (semana ISO, de segunda a domingo) e `AAAA` (ano). A tabela `agradecimentos` passa a aceitar a semana; o `unique (client_id, periodo)` já separa os três tipos, porque os formatos não se repetem.
- **Quem entra em cada lista** é filtrado na página, a partir da mesma função da US-39: mensal `total > 0`, semanal `doacoesDeItem > 0`, anual todos. O banco confere de novo no registro (o tipo de contribuição de cada período). A semanal não usa `pecas`: doação com a triagem pendente tem `pecas` 0, e a pessoa trouxe item do mesmo jeito (o registro no banco aceita, porque confere a existência da doação).
- **O mensal perde as peças** (a resposta 2 manda as peças para o semanal). Quem só doou item no mês sai da lista mensal.
- **Semana anterior e mês anterior por padrão:** o agradecimento é do que já aconteceu. A pessoa pode navegar para a semana ou o mês atual.
- **Textos:** propostos pela equipe, sem pedido de dado nem de pagamento, com o caminho para sair (responder SAIR), como na US-21a.

-- A semana (AAAA-Snn, semana ISO de segunda a domingo) entra como período, e o
-- registro passa a conferir o tipo de contribuição de cada período: semana, item;
-- mês, compra ou dinheiro; ano, qualquer uma.

-- ─────────────────────────────────────────
-- 1. A tabela aceita a semana. Confira o nome da constraint com
--    \d public.agradecimentos (o nome automático é agradecimentos_periodo_check).
-- ─────────────────────────────────────────

alter table public.agradecimentos drop constraint if exists agradecimentos_periodo_check;
alter table public.agradecimentos
  add constraint agradecimentos_periodo_check
  check (periodo ~ '^\d{4}(-(0[1-9]|1[0-2])|-S(0[1-9]|[1-4][0-9]|5[0-3]))?$');

-- ─────────────────────────────────────────
-- 2. O intervalo da semana.
-- ─────────────────────────────────────────

create or replace function public.intervalo_do_periodo(p_periodo text, out desde timestamptz, out ate timestamptz)
language plpgsql
stable
set search_path = ''
as $$
declare
  v_inicio date;
  v_fim    date;
begin
  if p_periodo ~ '^\d{4}-(0[1-9]|1[0-2])$' then
    v_inicio := to_date(p_periodo || '-01', 'YYYY-MM-DD');
    v_fim := (v_inicio + interval '1 month')::date;
  elsif p_periodo ~ '^\d{4}-S(0[1-9]|[1-4][0-9]|5[0-3])$' then
    -- Segunda-feira da semana ISO: ano ISO, semana ISO e dia 1.
    v_inicio := to_date(replace(p_periodo, '-S', '-') || '-1', 'IYYY-IW-ID');
    v_fim := v_inicio + 7;
  elsif p_periodo ~ '^\d{4}$' then
    v_inicio := to_date(p_periodo || '-01-01', 'YYYY-MM-DD');
    v_fim := (v_inicio + interval '1 year')::date;
  else
    raise exception 'período inválido' using errcode = '22023';
  end if;
  desde := v_inicio::timestamp at time zone 'America/Sao_Paulo';
  ate := v_fim::timestamp at time zone 'America/Sao_Paulo';
end;
$$;

-- ─────────────────────────────────────────
-- 3. O registro confere o tipo de contribuição do período.
-- ─────────────────────────────────────────

create or replace function public.registrar_agradecimento(p_client_id uuid, p_periodo text, p_canal text)
returns text
language plpgsql
security definer
set search_path = ''
as $$
declare
  v_desde    timestamptz;
  v_ate      timestamptz;
  v_compras  boolean;
  v_dinheiro boolean;
  v_itens    boolean;
  v_phone    text;
  v_email    text;
  v_contato  text;
begin
  if not public.eh_caixa_ou_coordenacao() then
    raise exception 'só o caixa e a coordenação agradecem' using errcode = '42501';
  end if;
  if p_canal not in ('whatsapp', 'email') then
    raise exception 'canal inválido' using errcode = '22023';
  end if;
  select i.desde, i.ate into v_desde, v_ate from public.intervalo_do_periodo(p_periodo) i;

  v_compras := exists (select 1 from public.sales s where s.client_id = p_client_id and s.deleted_at is null and s.sold_at >= v_desde and s.sold_at < v_ate);
  v_dinheiro := exists (select 1 from public.donations_cash d where d.client_id = p_client_id and d.deleted_at is null and d.donated_at >= v_desde and d.donated_at < v_ate);
  v_itens := exists (select 1 from public.donations_items i where i.client_id = p_client_id and i.deleted_at is null and i.donated_at >= v_desde and i.donated_at < v_ate);

  if (p_periodo ~ '-S' and not v_itens)
     or (p_periodo ~ '^\d{4}-\d{2}$' and not (v_compras or v_dinheiro))
     or (p_periodo ~ '^\d{4}$' and not (v_compras or v_dinheiro or v_itens)) then
    raise exception 'esta pessoa não contribuiu neste período' using errcode = '22023';
  end if;

  select c.phone, c.email into v_phone, v_email from public.clients c where c.id = p_client_id;
  if p_canal = 'whatsapp' then
    v_contato := v_phone;
    if regexp_replace(coalesce(v_contato, ''), '\D', '', 'g') !~ '^(\d{10,11}|55\d{10,11})$' then
      raise exception 'sem telefone com DDD na ficha' using errcode = '22023';
    end if;
  else
    v_contato := v_email;
    if coalesce(v_contato, '') !~ '^[^\s@]+@[^\s@]+\.[^\s@]+$' then
      raise exception 'sem e-mail válido na ficha' using errcode = '22023';
    end if;
  end if;

  insert into public.agradecimentos (client_id, periodo, canal, term_version)
  values (p_client_id, p_periodo, p_canal, '');

  return v_contato;
end;
$$;

## Parte B · `lib/periodos.ts` (arquivo novo)

```ts
// US-41 · Períodos do agradecimento: mês (AAAA-MM), semana ISO (AAAA-Snn, de
// segunda a domingo) e ano (AAAA). Datas em texto AAAA-MM-DD, no dia de São Paulo.

export type TipoDeAgradecimento = 'mensal' | 'semanal' | 'anual'

export const FORMATO: Record<TipoDeAgradecimento, RegExp> = {
  mensal: /^\d{4}-(0[1-9]|1[0-2])$/,
  semanal: /^\d{4}-S(0[1-9]|[1-4]\d|5[0-3])$/,
  anual: /^\d{4}$/,
}

const NOMES_DOS_MESES = ['Janeiro', 'Fevereiro', 'Março', 'Abril', 'Maio', 'Junho', 'Julho', 'Agosto', 'Setembro', 'Outubro', 'Novembro', 'Dezembro']

function utc(dia: string): Date {
  const [y, m, d] = dia.split('-').map(Number)
  return new Date(Date.UTC(y, m - 1, d))
}

const texto = (d: Date) => d.toISOString().slice(0, 10)

export function somarDias(dia: string, n: number): string {
  const d = utc(dia)
  d.setUTCDate(d.getUTCDate() + n)
  return texto(d)
}

// Semana ISO de um dia: a semana é do ano da sua quinta-feira.
export function semanaDe(dia: string): string {
  const t = utc(dia)
  t.setUTCDate(t.getUTCDate() + 4 - (t.getUTCDay() || 7))
  const ano = t.getUTCFullYear()
  const semana = Math.ceil(((t.getTime() - Date.UTC(ano, 0, 1)) / 86400000 + 1) / 7)
  return `${ano}-S${String(semana).padStart(2, '0')}`
}

// Segunda-feira de uma semana ISO: a semana 1 é a que tem o dia 4 de janeiro.
export function segundaDaSemana(periodo: string): string {
  const ano = Number(periodo.slice(0, 4))
  const semana = Number(periodo.slice(6))
  const jan4 = new Date(Date.UTC(ano, 0, 4))
  const segunda = new Date(jan4)
  segunda.setUTCDate(5 - (jan4.getUTCDay() || 7) + (semana - 1) * 7)
  return texto(segunda)
}

export function outroPeriodo(tipo: TipoDeAgradecimento, periodo: string, passo: number): string {
  if (tipo === 'anual') return String(Number(periodo) + passo)
  if (tipo === 'semanal') return semanaDe(somarDias(segundaDaSemana(periodo), 7 * passo))
  const [ano, mes] = periodo.split('-').map(Number)
  const d = new Date(Date.UTC(ano, mes - 1 + passo, 1))
  return `${d.getUTCFullYear()}-${String(d.getUTCMonth() + 1).padStart(2, '0')}`
}

// Onde cada aba abre: mês anterior, semana anterior e ano atual.
export function periodoPadrao(tipo: TipoDeAgradecimento, hoje: string): string {
  if (tipo === 'anual') return hoje.slice(0, 4)
  if (tipo === 'semanal') return semanaDe(somarDias(hoje, -7))
  return outroPeriodo('mensal', hoje.slice(0, 7), -1)
}

export function nomeDoPeriodo(tipo: TipoDeAgradecimento, periodo: string): string {
  if (tipo === 'anual') return periodo
  if (tipo === 'mensal') {
    const [ano, mes] = periodo.split('-').map(Number)
    return `${NOMES_DOS_MESES[mes - 1]} de ${ano}`
  }
  const inicio = segundaDaSemana(periodo)
  const fim = somarDias(inicio, 6)
  const br = (d: string) => d.split('-').reverse().slice(0, 2).join('/')
  return `semana de ${br(inicio)} a ${br(fim)}/${fim.slice(0, 4)}`
}
```

Teste rápido de mesa (escreva no PR o que conferiu): `semanaDe('2026-11-15')` é `2026-S46` (domingo); `semanaDe('2026-11-16')` é `2026-S47`; `segundaDaSemana('2026-S47')` é `2026-11-16`; `semanaDe('2027-01-01')` é `2026-S53`; `outroPeriodo('semanal', '2026-S53', 1)` é `2027-S01`.

// Mensal (resposta 2): compras no brechó e doações em dinheiro do mês, com os atendimentos.
export function textoDeAgradecimento(p: { nome: string; mes: number; valor: number; atendimentos: string }): string {
  const primeiroNome = p.nome.trim().split(/\s+/)[0] ?? ''
  const reais = `R$ ${p.valor.toLocaleString('pt-BR', { minimumFractionDigits: 2, maximumFractionDigits: 2 })}`
  return (
    `Olá, ${primeiroNome}! Em ${MESES_POR_EXTENSO[p.mes - 1]}, você contribuiu com ${reais} com o Instituto Camaleão, ` +
    `o que ajuda a custear ${p.atendimentos} de pessoas em tratamento de câncer. ` +
    'Nosso muito obrigado por fazer parte desta história. ' +
    'Se não quiser mais receber mensagens do Instituto, é só responder SAIR.'
  )
}

// Semanal (resposta 2): mensagem padrão para quem trouxe item na sede, sem dizer o quê.
export function textoDeAgradecimentoSemanal(nome: string): string {
  const primeiroNome = nome.trim().split(/\s+/)[0] ?? ''
  return (
    `Olá, ${primeiroNome}! Obrigado pela doação que você trouxe ao Instituto Camaleão nesta semana. ` +
    'Cada doação que chega à nossa sede ajuda a manter os atendimentos de quem está em tratamento de câncer. ' +
    'Se não quiser mais receber mensagens do Instituto, é só responder SAIR.'
  )
}

// Anual (resposta 2): o total do ano com os atendimentos; quem só doou item, texto fixo.
export function textoDeAgradecimentoAnual(p: { nome: string; ano: number; valor: number; atendimentos: string }): string {
  const primeiroNome = p.nome.trim().split(/\s+/)[0] ?? ''
  const fim = 'Obrigado por estar com a gente. Se não quiser mais receber mensagens do Instituto, é só responder SAIR.'
  if (p.valor > 0) {
    const reais = `R$ ${p.valor.toLocaleString('pt-BR', { minimumFractionDigits: 2, maximumFractionDigits: 2 })}`
    return `Olá, ${primeiroNome}! Em ${p.ano}, você contribuiu com ${reais} com o Instituto Camaleão, o que ajudou a custear ${p.atendimentos} de pessoas em tratamento de câncer. ${fim}`
  }
  return `Olá, ${primeiroNome}! Em ${p.ano}, suas doações à sede do Instituto Camaleão fizeram diferença para quem está em tratamento de câncer. ${fim}`
}
```

                ) : p.termoQueNaoVale ? (
                  'Autorizou um termo que não vale (veja a ficha)'
                ) : !p.podeReceber ? (
                  'Sem autorização de mensagens'
                ) : !p.temWhatsApp && !p.temEmail ? (
                  'Autorizou, mas não tem contato registrado'
                ) : (
                  <BotaoDeAgradecer clientId={p.id} periodo={periodo} texto={textoPara(p)} temWhatsApp={p.temWhatsApp} temEmail={p.temEmail} />
                )}
              </div>
            </li>
          ))}
        </ul>
      )}
      {semAutorizacao > 0 && (
        <p className="font-body text-xs text-muted mt-3">
          {semAutorizacao} {semAutorizacao === 1 ? 'pessoa contribuiu e não pode' : 'pessoas contribuíram e não podem'} receber mensagem: não autorizaram, autorizaram um termo anterior (veja a ficha){termoAprovado ? '' : ' ou o termo ainda não foi aprovado'}.
        </p>
      )}
    </div>
  )
}
```

O link antigo `?mes=AAAA-MM` deixa de valer: confira com `grep -rn "agradecimentos?mes" app components tests` e troque para `?tipo=mensal&periodo=AAAA-MM`.
