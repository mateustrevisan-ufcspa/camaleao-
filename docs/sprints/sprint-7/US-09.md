# US-09 · Importação de pessoas a partir de planilha (8 SP)

> Como coordenadora do Instituto, eu quero trazer para o sistema os nomes e contatos que já estão na planilha do brechó, para que a ficha única comece com o histórico de quem já é conhecido, e não vazia.

**Tipo:** user story · **Implementa:** Mateus · **Revisa:** Bibiana · **Branch:** `us-09-importacao-de-pessoas` · **Depende de:** nada da sprint (as planilhas reais **não** são necessárias para implementar) · **PR pronto:** quarta 11/11, 18h · **Merge:** quarta 11/11, à noite, depois da SEC-04

## Por que entra agora, sem as planilhas

O cartão dizia que a US-09 esperava as planilhas reais. Elas decidem **o que** será importado, e não **como**. A tela deixa a coordenadora dizer qual coluna é o nome, o telefone, o e-mail e o aniversário, então o formato de cada planilha não precisa ser conhecido antes. A equipe testa com uma planilha fictícia e com a planilha modelo que a tela oferece para baixar. A importação dos dados verdadeiros fica para o cartão "Início do uso pelo Instituto", feita pela própria coordenação, quando as planilhas chegarem (pergunta 5 da mensagem de 06/11).

## Critérios de aceitação

- [ ] Aceita arquivo `.xlsx` de até 900 KB e até 2.000 linhas, lê a primeira aba e sugere quais colunas são nome, telefone, e-mail e aniversário, pelo título; a coordenadora confirma ou troca
- [ ] Valida e normaliza cada campo (nome sem espaços sobrando, telefone com DDD no formato do sistema, e-mail em minúsculas, aniversário como dd/mm); campo inválido é descartado com aviso na linha, e linha sem nome não entra
- [ ] Nada do arquivo é interpretado como comando: o conteúdo vira texto, inclusive o que começa com `=`, e as exportações em CSV das listas passam a neutralizar células que começam com sinal de fórmula (a planilha do relatório já faz isso desde a US-18)
- [ ] Antes de gravar, a tela mostra cada linha com a situação: nova, repetida na planilha (com a linha igual) ou já cadastrada (com o nome da ficha); a coordenadora marca e desmarca o que entra
- [ ] Depois de gravar, informa quantas pessoas foram importadas e quantas descartadas, e a importação fica registrada (quem, quando, arquivo e contagens)
- [ ] Quem é importado entra como "ainda não perguntada" nas mensagens (US-07): não recebe nada até autorizar
- [ ] Só a coordenação abre a tela e usa as funções; testes de fumaça e de acesso passam

## Decisões

- **Só `.xlsx`**, lido no servidor com a biblioteca `read-excel-file` (do mesmo autor da `write-excel-file`, que o projeto já usa). Planilha em `.csv` ou do Google: abrir e salvar como `.xlsx`. A biblioteca lê os valores já calculados das células e nunca executa fórmula.
- **Limites:** 900 KB (abaixo do limite de 1 MB do corpo das Server Actions do Next, sem mudar a configuração) e 2.000 linhas de dados.
- **Repetidas:** dentro da planilha, pelo final do telefone (8 dígitos, como a US-08a) ou, sem telefone, pelo nome sem acento e em minúsculas. Contra o sistema, a mesma regra, por uma função do banco que só a coordenação usa e que não devolve telefone (SEC-05).
- **Já cadastrada não entra** (desmarcada e travada): a ficha existe, e duplicar só daria trabalho para a mesclagem. Repetida na planilha: a primeira ocorrência vem marcada e as outras desmarcadas; a coordenadora pode trocar.
- **O servidor refaz tudo** ao gravar: normalização e repetidas são conferidas de novo com o que chegou do navegador.
- **Ano de entrada (`member_since`)** fica vazio: a planilha não diz desde quando a pessoa conhece o Instituto.

```sql
-- US-09 · Importação de pessoas a partir de planilha
-- Função que diz quais linhas da planilha já têm ficha, sem devolver telefone,
-- e o registro de cada importação. Só a coordenação.

-- ─────────────────────────────────────────
-- 1. pessoas_ja_cadastradas: para cada posição das listas, a ficha que já
--    existe com o mesmo final de telefone (8 dígitos) ou, sem telefone, com o
--    mesmo nome (sem acento, em minúsculas: nome_para_comparar, da US-08a).
--    security definer porque compara telefones, que nenhum perfil lê direto
--    (SEC-05). Começa por eh_coordenacao(): para o balcão, nada.
-- ─────────────────────────────────────────

create or replace function public.pessoas_ja_cadastradas(p_telefones text[], p_nomes text[])
returns table (posicao int, client_id uuid, nome text, motivo text)
language sql
stable
security definer
set search_path = ''
as $$
  with entrada as (
    select e.posicao::int as posicao,
           right(regexp_replace(coalesce(e.telefone, ''), '\D', '', 'g'), 8) as final,
           public.nome_para_comparar(btrim(coalesce(n.nome, ''))) as nome
      from unnest(p_telefones) with ordinality as e(telefone, posicao)
      join unnest(p_nomes) with ordinality as n(nome, posicao) using (posicao)
     where public.eh_coordenacao()
  )
  select distinct on (en.posicao)
         en.posicao, c.id, c.name,
         case when length(en.final) = 8
                   and right(regexp_replace(coalesce(c.phone, ''), '\D', '', 'g'), 8) = en.final
              then 'telefone' else 'nome' end
    from entrada en
    join public.clients c
      on (length(en.final) = 8 and right(regexp_replace(coalesce(c.phone, ''), '\D', '', 'g'), 8) = en.final)
      or (length(en.final) < 8 and en.nome <> '' and public.nome_para_comparar(c.name) = en.nome)
   order by en.posicao, c.created_at
$$;

revoke execute on function public.pessoas_ja_cadastradas(text[], text[]) from public, anon;
grant execute on function public.pessoas_ja_cadastradas(text[], text[]) to authenticated;

-- ─────────────────────────────────────────
-- 2. Registro de cada importação. Quem e quando vêm do banco.
-- ─────────────────────────────────────────

create table public.importacoes_de_pessoas (
  id          uuid primary key default gen_random_uuid(),
  arquivo     text not null check (length(arquivo) between 1 and 200),
  importadas  int not null check (importadas >= 0),
  descartadas int not null check (descartadas >= 0),
  feita_em    timestamptz not null default now(),
  feita_por   uuid references public.users(id) on delete set null
);

create or replace function public.carimbar_importacao()
returns trigger
language plpgsql
set search_path = ''
as $$
begin
  new.feita_em := now();
  new.feita_por := auth.uid();
  return new;
end;
$$;

create trigger carimbo_da_importacao
  before insert on public.importacoes_de_pessoas
  for each row execute function public.carimbar_importacao();

alter table public.importacoes_de_pessoas enable row level security;

create policy "coordenacao le" on public.importacoes_de_pessoas
  for select to authenticated using (public.eh_coordenacao());
create policy "coordenacao registra" on public.importacoes_de_pessoas
  for insert to authenticated with check (public.eh_coordenacao());

revoke all on public.importacoes_de_pessoas from anon;
grant select, insert on public.importacoes_de_pessoas to authenticated;
```

```ts
// US-09 · Importação de pessoas a partir de planilha: leitura das colunas e
// normalização dos campos. Sem banco: o servidor e os testes usam as mesmas regras.

export const TAMANHO_MAXIMO = 900 * 1024
export const LINHAS_MAXIMAS = 2000

export type Campo = 'nome' | 'telefone' | 'email' | 'aniversario'
export type Mapa = Record<Campo, number | null>

export const ROTULOS: Record<Campo, string> = {
  nome: 'Nome',
  telefone: 'Telefone',
  email: 'E-mail',
  aniversario: 'Aniversário',
}

const semAcento = (t: string) => t.normalize('NFD').replace(/[̀-ͯ]/g, '').toLowerCase().trim()

// Títulos de coluna que costumam aparecer em planilhas de cadastro.
const PALAVRAS: Record<Campo, string[]> = {
  nome: ['nome', 'cliente', 'doador', 'doadora', 'apoiador', 'pessoa'],
  telefone: ['telefone', 'celular', 'whatsapp', 'whats', 'fone', 'contato'],
  email: ['e-mail', 'email', 'mail'],
  aniversario: ['aniversario', 'nascimento', 'data de nascimento', 'niver'],
}

export function sugerirMapa(cabecalho: string[]): Mapa {
  const titulos = cabecalho.map((c) => semAcento(c ?? ''))
  const achar = (campo: Campo) => {
    const i = titulos.findIndex((t) => PALAVRAS[campo].some((p) => t === p || t.startsWith(`${p} `) || t.includes(p)))
    return i >= 0 ? i : null
  }
  return { nome: achar('nome'), telefone: achar('telefone'), email: achar('email'), aniversario: achar('aniversario') }
}

// Valor de célula como texto. Data vira AAAA-MM-DD (as datas chegam em UTC).
export function textoDaCelula(v: unknown): string {
  if (v === null || v === undefined) return ''
  if (v instanceof Date) return Number.isNaN(v.getTime()) ? '' : v.toISOString().slice(0, 10)
  return String(v).trim()
}

export function normalizarNome(v: string): string | null {
  const nome = v.replace(/\s+/g, ' ').trim()
  return nome.length >= 2 && nome.length <= 120 ? nome : null
}

// "51 99812 3344", "+55 (51) 99812-3344" e "51998123344" viram "(51) 99812-3344".
export function normalizarTelefone(v: string): string | null {
  let d = v.replace(/\D/g, '')
  if ((d.length === 12 || d.length === 13) && d.startsWith('55')) d = d.slice(2)
  if (d.length === 11) return `(${d.slice(0, 2)}) ${d.slice(2, 7)}-${d.slice(7)}`
  if (d.length === 10) return `(${d.slice(0, 2)}) ${d.slice(2, 6)}-${d.slice(6)}`
  return null
}

export function normalizarEmail(v: string): string | null {
  const e = v.trim().toLowerCase()
  return /^[^\s@]+@[^\s@]+\.[^\s@]+$/.test(e) && e.length <= 120 ? e : null
}

// O sistema guarda o aniversário como "dd/mm", sem o ano (US-22).
export function normalizarAniversario(v: string): string | null {
  const t = v.trim()
  let dia: number, mes: number
  const iso = t.match(/^(\d{4})-(\d{2})-(\d{2})/)
  const br = t.match(/^(\d{1,2})\/(\d{1,2})(?:\/\d{2,4})?$/)
  if (iso) [dia, mes] = [Number(iso[3]), Number(iso[2])]
  else if (br) [dia, mes] = [Number(br[1]), Number(br[2])]
  else return null
  if (mes < 1 || mes > 12 || dia < 1 || dia > 31) return null
  return `${String(dia).padStart(2, '0')}/${String(mes).padStart(2, '0')}`
}

export interface PessoaDaPlanilha {
  linha: number // número da linha na planilha, contando o título como 1
  nome: string | null
  telefone: string | null
  email: string | null
  aniversario: string | null
  avisos: string[]
}

export function lerPessoas(linhas: string[][], mapa: Mapa): PessoaDaPlanilha[] {
  const celula = (l: string[], campo: Campo) => (mapa[campo] === null ? '' : (l[mapa[campo] as number] ?? ''))
  return linhas.map((l, i) => {
    const avisos: string[] = []
    const nome = normalizarNome(celula(l, 'nome'))
    if (!nome) avisos.push('sem nome')
    const brutoTelefone = celula(l, 'telefone')
    const telefone = brutoTelefone ? normalizarTelefone(brutoTelefone) : null
    if (brutoTelefone && !telefone) avisos.push('telefone ignorado (sem DDD ou com dígitos a mais)')
    const brutoEmail = celula(l, 'email')
    const email = brutoEmail ? normalizarEmail(brutoEmail) : null
    if (brutoEmail && !email) avisos.push('e-mail ignorado')
    const brutoAniversario = celula(l, 'aniversario')
    const aniversario = brutoAniversario ? normalizarAniversario(brutoAniversario) : null
    if (brutoAniversario && !aniversario) avisos.push('aniversário ignorado')
    return { linha: i + 2, nome, telefone, email, aniversario, avisos }
  })
}

// Chave de repetição: final do telefone ou, sem telefone, o nome sem acento.
export function chaveDeRepeticao(p: { nome: string | null; telefone: string | null }): string | null {
  const final = (p.telefone ?? '').replace(/\D/g, '').slice(-8)
  if (final.length === 8) return `t:${final}`
  return p.nome ? `n:${semAcento(p.nome)}` : null
}

// Para cada pessoa, a linha anterior da planilha com a mesma chave (ou null).
export function repetidasNaPlanilha(pessoas: PessoaDaPlanilha[]): (number | null)[] {
  const primeira = new Map<string, number>()
  return pessoas.map((p) => {
    const chave = chaveDeRepeticao(p)
    if (!chave) return null
    const antes = primeira.get(chave)
    if (antes !== undefined) return antes
    primeira.set(chave, p.linha)
    return null
  })
}
```

```ts
// ── IMPORTAÇÃO DE PESSOAS (US-09) ──
// Quais posições das listas já têm ficha (a função do banco não devolve telefone).

export async function getPessoasJaCadastradas(
  telefones: (string | null)[],
  nomes: (string | null)[]
): Promise<Map<number, string>> {
  const supabase = await createClient()
  const { data, error } = await supabase.rpc('pessoas_ja_cadastradas', {
    p_telefones: telefones.map((t) => t ?? ''),
    p_nomes: nomes.map((n) => n ?? ''),
  })
  if (error) throw new Error(error.message)
  // A posição do banco começa em 1.
  return new Map((data ?? []).map((r: { posicao: number; nome: string }) => [r.posicao - 1, r.nome]))
}

export async function addPessoasImportadas(
  pessoas: { name: string; phone: string | null; email: string | null; birthday: string | null }[]
): Promise<number> {
  const supabase = await createClient()
  let gravadas = 0
  for (let i = 0; i < pessoas.length; i += 200) {
    const lote = pessoas.slice(i, i + 200).map((p) => ({ ...p, member_since: null }))
    const { data, error } = await supabase.from('clients').insert(lote).select('id')
    if (error) throw new Error(error.message)
    gravadas += (data ?? []).length
  }
  return gravadas
}

export async function addRegistroDeImportacao(arquivo: string, importadas: number, descartadas: number): Promise<void> {
  const supabase = await createClient()
  const { error } = await supabase.from('importacoes_de_pessoas').insert({ arquivo: arquivo.slice(0, 200) || 'planilha', importadas, descartadas })
  if (error) throw new Error(error.message)
}
```

## Parte F · `actions/importacao.ts` (arquivo novo)

```ts
'use server'

import { revalidatePath } from 'next/cache'
import { readSheet } from 'read-excel-file/node'
import { addPessoasImportadas, addRegistroDeImportacao, getPessoasJaCadastradas, souCoordenacao } from '@/lib/store'
import {
  LINHAS_MAXIMAS, TAMANHO_MAXIMO, lerPessoas, normalizarAniversario, normalizarEmail, normalizarNome,
  normalizarTelefone, repetidasNaPlanilha, sugerirMapa, textoDaCelula, type Mapa,
} from '@/lib/importacao'
import type { LinhaDaPrevia } from '@/types'

const AVISO_RESTRITO = 'Só a coordenação importa pessoas.'

async function lerArquivo(fd: FormData): Promise<{ erro: string } | { linhas: string[][]; arquivo: string }> {
  const arquivo = fd.get('arquivo')
  if (!(arquivo instanceof File) || arquivo.size === 0) return { erro: 'Escolha a planilha.' }
  if (!arquivo.name.toLowerCase().endsWith('.xlsx')) return { erro: 'A planilha precisa estar em .xlsx. No Excel ou no Google Planilhas, salve como .xlsx.' }
  if (arquivo.size > TAMANHO_MAXIMO) return { erro: 'A planilha passa de 900 KB. Divida em duas e importe uma de cada vez.' }
  try {
    // readSheet só lê os valores das células: nenhuma fórmula é executada.
    const dados = await readSheet(Buffer.from(await arquivo.arrayBuffer()))
    const linhas = dados.map((l) => l.slice(0, 26).map(textoDaCelula))
    if (linhas.length < 2) return { erro: 'A planilha está vazia ou só tem o título.' }
    if (linhas.length - 1 > LINHAS_MAXIMAS) return { erro: `A planilha tem mais de ${LINHAS_MAXIMAS} linhas. Divida e importe em partes.` }
    return { linhas, arquivo: arquivo.name }
  } catch (e) {
    console.error('lerArquivo error:', e)
    return { erro: 'Não foi possível ler a planilha. Confira se o arquivo é um .xlsx válido.' }
  }
}

// Passo 1: títulos, algumas linhas de amostra e a sugestão de colunas.
export async function lerPlanilha(fd: FormData): Promise<{ error: string } | { cabecalho: string[]; amostra: string[][]; total: number; mapa: Mapa }> {
  if (!(await souCoordenacao())) return { error: AVISO_RESTRITO }
  const lido = await lerArquivo(fd)
  if ('erro' in lido) return { error: lido.erro }
  const [cabecalho, ...resto] = lido.linhas
  return { cabecalho, amostra: resto.slice(0, 5), total: resto.length, mapa: sugerirMapa(cabecalho) }
}

function lerMapa(fd: FormData): Mapa {
  const coluna = (nome: string) => {
    const v = Number(fd.get(`coluna_${nome}`))
    return Number.isInteger(v) && v >= 0 && v < 26 ? v : null
  }
  return { nome: coluna('nome'), telefone: coluna('telefone'), email: coluna('email'), aniversario: coluna('aniversario') }
}

// Passo 2: cada linha normalizada, com a situação.
export async function prepararImportacao(fd: FormData): Promise<{ error: string } | { linhas: LinhaDaPrevia[] }> {
  if (!(await souCoordenacao())) return { error: AVISO_RESTRITO }
  const mapa = lerMapa(fd)
  if (mapa.nome === null) return { error: 'Escolha a coluna do nome.' }
  const lido = await lerArquivo(fd)
  if ('erro' in lido) return { error: lido.erro }

  const pessoas = lerPessoas(lido.linhas.slice(1), mapa)
  const repetidas = repetidasNaPlanilha(pessoas)
  const cadastradas = await getPessoasJaCadastradas(pessoas.map((p) => p.telefone), pessoas.map((p) => p.nome))

  return {
    linhas: pessoas.map((p, i): LinhaDaPrevia => ({
      ...p,
      situacao: !p.nome ? 'invalida' : cadastradas.has(i) ? 'cadastrada' : repetidas[i] !== null ? 'repetida' : 'nova',
      referencia: cadastradas.get(i) ?? (repetidas[i] !== null ? `linha ${repetidas[i]}` : null),
    })),
  }
}

// Passo 3: grava as linhas marcadas. Tudo é conferido de novo aqui.
export async function importarPessoas(entrada: {
  arquivo: string
  total: number
  pessoas: { nome: string; telefone: string | null; email: string | null; aniversario: string | null }[]
}): Promise<{ error: string } | { importadas: number; descartadas: number }> {
  if (!(await souCoordenacao())) return { error: AVISO_RESTRITO }
  if (!Array.isArray(entrada?.pessoas) || entrada.pessoas.length > LINHAS_MAXIMAS) return { error: 'Lista de pessoas inválida.' }

  const limpas = entrada.pessoas
    .map((p) => ({
      name: normalizarNome(String(p?.nome ?? '')),
      phone: p?.telefone ? normalizarTelefone(String(p.telefone)) : null,
      email: p?.email ? normalizarEmail(String(p.email)) : null,
      birthday: p?.aniversario ? normalizarAniversario(String(p.aniversario)) : null,
    }))
    .filter((p): p is { name: string; phone: string | null; email: string | null; birthday: string | null } => p.name !== null)

  // Quem já tem ficha não entra, mesmo que o navegador mande.
  const cadastradas = await getPessoasJaCadastradas(limpas.map((p) => p.phone), limpas.map((p) => p.name))
  const novas = limpas.filter((_, i) => !cadastradas.has(i))

  const total = Math.max(Number(entrada.total) || 0, entrada.pessoas.length)
  try {
    const importadas = novas.length > 0 ? await addPessoasImportadas(novas) : 0
    const descartadas = total - importadas
    await addRegistroDeImportacao(String(entrada.arquivo ?? ''), importadas, descartadas)
    revalidatePath('/clientes')
    return { importadas, descartadas }
  } catch (e) {
    console.error('importarPessoas error:', e)
    return { error: 'Não foi possível gravar a importação. Nenhuma ficha a mais foi criada se o erro veio no primeiro lote; confira em Clientes antes de tentar de novo.' }
  }
}
```

**Repetidas na planilha, no passo 3:** a coordenadora decide pela prévia. Se ela marcar duas linhas iguais, as duas entram; o servidor só barra quem já tem ficha.

```tsx
import { importarPessoas, lerPlanilha, prepararImportacao } from '@/actions/importacao'
import { ROTULOS, type Campo, type Mapa } from '@/lib/importacao'
import type { LinhaDaPrevia } from '@/types'

const CAMPOS: Campo[] = ['nome', 'telefone', 'email', 'aniversario']
const SITUACAO: Record<LinhaDaPrevia['situacao'], string> = {
  nova: 'Nova',
  repetida: 'Repetida na planilha',
  cadastrada: 'Já tem ficha',
  invalida: 'Sem nome',
}

export function ImportarPessoas() {
  const [isPending, startTransition] = useTransition()
  const [erro, setErro] = useState<string | null>(null)
  const [arquivo, setArquivo] = useState<File | null>(null)
  const [cabecalho, setCabecalho] = useState<string[] | null>(null)
  const [amostra, setAmostra] = useState<string[][]>([])
  const [total, setTotal] = useState(0)
  const [mapa, setMapa] = useState<Mapa | null>(null)
  const [previa, setPrevia] = useState<LinhaDaPrevia[] | null>(null)
  const [marcadas, setMarcadas] = useState<Set<number>>(new Set())
  const [resultado, setResultado] = useState<{ importadas: number; descartadas: number } | null>(null)

  function comArquivo(extra?: Record<string, string>) {
    const fd = new FormData()
    if (arquivo) fd.set('arquivo', arquivo)
    for (const [k, v] of Object.entries(extra ?? {})) fd.set(k, v)
    return fd
  }

  function ler() {
    setErro(null); setPrevia(null); setResultado(null)
    startTransition(async () => {
      const r = await lerPlanilha(comArquivo())
      if ('error' in r) return setErro(r.error)
      setCabecalho(r.cabecalho); setAmostra(r.amostra); setTotal(r.total); setMapa(r.mapa)
    })
  }

  function preparar() {
    if (!mapa) return
    setErro(null)
    const colunas = Object.fromEntries(CAMPOS.map((c) => [`coluna_${c}`, mapa[c] === null ? '' : String(mapa[c])]))
    startTransition(async () => {
      const r = await prepararImportacao(comArquivo(colunas))
      if ('error' in r) return setErro(r.error)
      setPrevia(r.linhas)
      setMarcadas(new Set(r.linhas.filter((l) => l.situacao === 'nova').map((l) => l.linha)))
    })
  }

  function importar() {
    if (!previa || !arquivo) return
    setErro(null)
    const pessoas = previa
      .filter((l) => marcadas.has(l.linha) && l.nome)
      .map((l) => ({ nome: l.nome as string, telefone: l.telefone, email: l.email, aniversario: l.aniversario }))
    startTransition(async () => {
      const r = await importarPessoas({ arquivo: arquivo.name, total: previa.length, pessoas })
      if ('error' in r) return setErro(r.error)
      setResultado(r); setPrevia(null); setCabecalho(null); setArquivo(null)
    })
  }

  function alternar(linha: number) {
    setMarcadas((m) => {
      const nova = new Set(m)
      if (nova.has(linha)) nova.delete(linha)
      else nova.add(linha)
      return nova
    })
  }

  return (
    <div className="flex flex-col gap-6 font-body">
      {resultado && (
        <div data-testid="resultado-da-importacao" className="rounded-[12px] px-5 py-4 text-sm" style={{ backgroundColor: '#DCEBE0', color: '#2E5C3E' }}>
          {resultado.importadas} {resultado.importadas === 1 ? 'pessoa importada' : 'pessoas importadas'} e{' '}
          {resultado.descartadas} {resultado.descartadas === 1 ? 'descartada' : 'descartadas'}.{' '}
          <Link href="/clientes" className="text-emerald">Ver as fichas</Link>
        </div>
      )}

      <section className="bg-paper border border-rule rounded-[16px] p-6">
        <h2 className="font-display text-xl text-ink m-0 mb-2">1. Planilha</h2>
        <p className="text-sm text-muted mt-0">
          Arquivo .xlsx de até 900 KB e 2.000 linhas; a primeira linha precisa ter os títulos das colunas.{' '}
          <a href="/clientes/importar/modelo" download className="text-accent-deep">Baixar a planilha modelo</a>.
        </p>
        <div className="flex flex-wrap gap-3 items-center">
          <input aria-label="Planilha" type="file" accept=".xlsx" onChange={(e) => { setArquivo(e.target.files?.[0] ?? null); setCabecalho(null); setPrevia(null) }} />
          <button type="button" onClick={ler} disabled={!arquivo || isPending} className="chip bg-ink text-bg border-ink disabled:opacity-50">Ler planilha</button>
        </div>
      </section>

      {cabecalho && mapa && (
        <section className="bg-paper border border-rule rounded-[16px] p-6">
          <h2 className="font-display text-xl text-ink m-0 mb-2">2. Colunas</h2>
          <p className="text-sm text-muted mt-0">{total} linhas. Confira qual coluna é cada informação; só o nome é obrigatório.</p>
          <div className="grid grid-cols-2 md:grid-cols-4 gap-3 mb-4">
            {CAMPOS.map((c) => (
              <div key={c}>
                <label htmlFor={`coluna-${c}`} className="block text-[11px] text-muted tracking-[1px] uppercase mb-1.5">{ROTULOS[c]}</label>
                <select
                  id={`coluna-${c}`}
                  value={mapa[c] === null ? '' : String(mapa[c])}
                  onChange={(e) => setMapa({ ...mapa, [c]: e.target.value === '' ? null : Number(e.target.value) })}
                  className="input-base"
                >
                  <option value="">Não tem</option>
                  {cabecalho.map((titulo, i) => <option key={i} value={i}>{titulo || `Coluna ${i + 1}`}</option>)}
                </select>
              </div>
            ))}
          </div>
          <table className="w-full text-xs border-collapse mb-4">
            <tbody>
              {amostra.map((l, i) => (
                <tr key={i} className="border-t border-rule">
                  {CAMPOS.map((c) => <td key={c} className="py-1.5 pr-3 text-ink">{mapa[c] === null ? '' : l[mapa[c] as number]}</td>)}
                </tr>
              ))}
            </tbody>
          </table>
          <button type="button" onClick={preparar} disabled={mapa.nome === null || isPending} className="chip bg-ink text-bg border-ink disabled:opacity-50">Conferir as linhas</button>
        </section>
      )}

      {previa && (
        <section className="bg-paper border border-rule rounded-[16px] p-6">
          <h2 className="font-display text-xl text-ink m-0 mb-2">3. Conferir e importar</h2>
          <p className="text-sm text-muted mt-0">{marcadas.size} de {previa.length} marcadas. Quem já tem ficha não entra.</p>
          <div className="overflow-x-auto">
            <table data-testid="previa" className="w-full text-[13px] border-collapse min-w-[760px]">
              <thead>
                <tr className="text-left text-[11px] text-muted uppercase tracking-[1px]">
                  <th className="py-2 pr-3">Entra</th><th className="py-2 pr-3">Linha</th><th className="py-2 pr-3">Nome</th>
                  <th className="py-2 pr-3">Telefone</th><th className="py-2 pr-3">E-mail</th><th className="py-2 pr-3">Aniversário</th><th className="py-2 pr-3">Situação</th>
                </tr>
              </thead>
              <tbody>
                {previa.map((l) => (
                  <tr key={l.linha} data-testid="linha-da-previa" className="border-t border-rule align-top">
                    <td className="py-2 pr-3">
                      <input
                        type="checkbox"
                        aria-label={`Importar a linha ${l.linha}`}
                        checked={marcadas.has(l.linha)}
                        disabled={l.situacao === 'cadastrada' || l.situacao === 'invalida'}
                        onChange={() => alternar(l.linha)}
                      />
                    </td>
                    <td className="py-2 pr-3 text-muted">{l.linha}</td>
                    <td className="py-2 pr-3 text-ink">{l.nome ?? '·'}</td>
                    <td className="py-2 pr-3 text-ink">{l.telefone ?? ''}</td>
                    <td className="py-2 pr-3 text-ink">{l.email ?? ''}</td>
                    <td className="py-2 pr-3 text-ink">{l.aniversario ?? ''}</td>
                    <td data-testid="situacao" className="py-2 pr-3 text-ink">
                      {SITUACAO[l.situacao]}{l.referencia ? ` (${l.referencia})` : ''}
                      {l.avisos.filter((a) => a !== 'sem nome').map((a) => <div key={a} className="text-xs text-muted">{a}</div>)}
                    </td>
                  </tr>
                ))}
              </tbody>
            </table>
          </div>
          <button type="button" onClick={importar} disabled={marcadas.size === 0 || isPending} className="chip bg-emerald text-white border-emerald mt-4 disabled:opacity-50">
            {isPending ? 'Importando...' : `Importar ${marcadas.size} ${marcadas.size === 1 ? 'pessoa' : 'pessoas'}`}
          </button>
        </section>
      )}

      {erro && <div role="alert" className="rounded-[10px] px-4 py-3 text-[13px]" style={{ backgroundColor: '#F8DCD2', color: '#D87560' }}>{erro}</div>}
    </div>
  )
}
```

```ts
import { NextResponse } from 'next/server'
import writeExcelFile from 'write-excel-file/node'
import { souCoordenacao } from '@/lib/store'
import { cabecalho, texto } from '@/lib/planilha'

// US-09 · Planilha modelo, com os títulos que a importação reconhece e uma linha de exemplo.
export async function GET() {
  if (!(await souCoordenacao())) return new NextResponse('Essa área é restrita à coordenação do Instituto.', { status: 403 })
  const planilha = await writeExcelFile([
    {
      sheet: 'Pessoas',
      data: [
        cabecalho(['Nome', 'Telefone', 'E-mail', 'Aniversário']),
        [texto('Maria Exemplo'), texto('(51) 99999-0000'), texto('maria@exemplo.com'), texto('14/06')],
      ],
      columns: [{ width: 32 }, { width: 18 }, { width: 28 }, { width: 14 }],
    },
  ]).toBuffer()
  return new NextResponse(new Uint8Array(planilha), {
    headers: {
      'Content-Type': 'application/vnd.openxmlformats-officedocument.spreadsheetml.sheet',
      'Content-Disposition': 'attachment; filename="modelo-importacao-de-pessoas.xlsx"',
      'Cache-Control': 'no-store',
    },
  })
}
```

```ts
import { test, expect } from '@playwright/test'

import { normalizarAniversario, normalizarTelefone, repetidasNaPlanilha, lerPessoas, sugerirMapa } from '../../lib/importacao'
```

```ts
// US-09 · Só a coordenação usa a função de repetidas e o registro de importações.
import { test, expect } from '@playwright/test'
import { CAIXA, COORDENACAO, entrarNaApi, recusado } from './apoio'

  expect(JSON.stringify(r.data)).not.toContain('99812')
})
```
