# US-31 · Comissão por doação, com quem captou (8 SP)

> Como coordenadora do financeiro, eu quero marcar em cada doação se teve comissão e para quem, com o percentual calculado pelo sistema, e somar o mês todo ou só algumas doações, para que o resultado do mês no sistema bata com a planilha do Instituto.

**Tipo:** user story · **Implementa:** Bibiana · **Revisa:** Mateus · **Branch:** `us-31-comissao-por-doacao` · **Depende de:** US-35 integrada (a comissão é sobre o líquido) e SEC-04 (a comissão entra na trilha) · **PR pronto:** quinta 12/11, 18h · **Merge:** quinta 12/11, à noite, depois da US-21a

**Reestimada de 5 para 8 SP** no planejamento de 06/11 (comissão por doação, e não por mês). **Redesenhada em 09/11, sem mudar os 8 SP,** com a resposta 7 da Nílian: a comissão é de **25% sobre o líquido**, com o percentual ajustável pela coordenação; em cada registro, marcar **se teve ou não comissão** e **para quem** (normalmente a Ana, mas a comissão é do trabalho, e não da pessoa); vale para vendas **e** doações, paga todo mês. Decisão do Mateus em 09/11: esta story fica só com as **doações em dinheiro**; a comissão nas **vendas** vira story nova para a Sprint 8, com as mesmas tabelas.

O que saiu do desenho de 06/11: o valor da comissão digitado à mão. O que entrou: a tabela do percentual (no padrão do valor do atendimento da US-19, uma linha por alteração) e a marcação "sem comissão".

## Critérios de aceitação

- [ ] A coordenação cadastra quem capta (nome) e desativa quem parou; quem foi desativado continua nas comissões antigas
- [ ] O percentual da comissão começa em 25% e a coordenação altera na tela; cada alteração é uma linha nova, com quem e quando vindos do banco, e ninguém altera nem apaga uma linha
- [ ] Em cada doação em dinheiro, a coordenação marca "teve comissão, para quem" ou "sem comissão", e corrige ou desmarca depois; a tela mostra quantas doações do mês ainda estão sem marcação
- [ ] A comissão é calculada pelo banco: percentual em vigor na hora da marcação, sobre o líquido da doação (US-35); sem líquido (taxa não cadastrada), a comissão fica "a calcular"
- [ ] A tela soma a comissão do mês inteiro, por pessoa que captou, e das doações que a coordenação marcar para somar
- [ ] O relatório consolidado e a exportação mostram as comissões do período e o resultado depois delas
- [ ] Quem marcou e quando vêm do banco, e cada correção entra na trilha de auditoria (SEC-04)
- [ ] O balcão não vê nem altera comissão, percentual nem quem capta; testes de acesso e de fumaça passam

## Decisões

- **Tabela própria, e não coluna na doação:** `comissoes_de_doacao`, uma linha por doação marcada, com a política "só a coordenação". O caixa lê as doações do dia (US-28) e, com coluna na própria doação, leria a comissão também.
- **Quem capta é um cadastro simples** (`captadores`: nome e ativo), e não uma conta do sistema: a comissão é do trabalho, e nem todos que captam usam o sistema. Sem nome de ninguém na migração; a coordenação cadastra a Ana na tela.
- **Percentual numa tabela própria** (`percentual_de_comissao`), igual ao valor do atendimento (US-19): o em vigor é o da linha mais recente. Começa com 25,00.
- **O percentual fica gravado na marcação** (como a taxa na US-35): alterar o percentual vale para as próximas marcações e não muda as antigas. Para aplicar o percentual novo a uma doação já marcada, desmarcar e marcar de novo.
- **O valor da comissão não é gravado:** a `comissoes_view` calcula `líquido × percentual ÷ 100` na leitura. Se o valor da doação for corrigido (US-04b), a comissão acompanha sozinha.
- **Sobre o líquido de qualquer doação** (`net_amount`), como a Nílian respondeu. No Pix da PagBank (0,19%, pergunta 18) e na Doação Solutions (pergunta 17), o líquido depende da taxa cadastrada; sem taxa, a comissão fica "a calcular".
- **Três situações por doação:** sem linha (a marcar), `teve_comissao = true` com quem captou, ou `teve_comissao = false` sem ninguém. O banco recusa as combinações erradas.
- **Marcar para somar** é só na tela (não grava). Pagamento da comissão não foi pedido como registro.
- **Doação cancelada (US-04b) sai das somas sozinha:** a view junta com `donations_cash`, que esconde as canceladas pela política do banco.

```sql
-- US-31 · Comissão por doação, com quem captou
-- Cadastro de quem capta, o percentual da comissão (uma linha por alteração, como
-- o valor do atendimento da US-19), a marcação de cada doação em dinheiro (teve ou
-- não comissão, para quem) e a view que calcula o valor sobre o líquido. Só a coordenação.

-- ─────────────────────────────────────────
-- 1. Quem capta. Desativar em vez de apagar: as comissões antigas apontam para cá.
-- ─────────────────────────────────────────

create table public.captadores (
  id         uuid primary key default gen_random_uuid(),
  nome       text not null check (length(btrim(nome)) between 2 and 80),
  ativo      boolean not null default true,
  criado_em  timestamptz not null default now(),
  criado_por uuid default auth.uid() references public.users(id) on delete set null
);

create unique index idx_captadores_nome on public.captadores (lower(btrim(nome)));

alter table public.captadores enable row level security;

create policy "coordenacao le" on public.captadores
  for select to authenticated using (public.eh_coordenacao());
create policy "coordenacao cadastra" on public.captadores
  for insert to authenticated with check (public.eh_coordenacao());
create policy "coordenacao altera" on public.captadores
  for update to authenticated using (public.eh_coordenacao()) with check (public.eh_coordenacao());

revoke all on public.captadores from anon;
grant select, insert, update on public.captadores to authenticated;

-- ─────────────────────────────────────────
-- 2. Percentual da comissão. Ninguém altera nem apaga uma linha: alterar o
--    percentual é inserir outra. O em vigor é o da linha mais recente.
-- ─────────────────────────────────────────

create table public.percentual_de_comissao (
  id           uuid primary key default gen_random_uuid(),
  percentual   numeric(5,2) not null check (percentual >= 0 and percentual <= 100),
  definido_em  timestamptz not null default now(),
  definido_por uuid references public.users(id) on delete set null
);

create index idx_percentual_de_comissao_definido_em
  on public.percentual_de_comissao (definido_em desc);

create or replace function public.carimbar_percentual_de_comissao()
returns trigger
language plpgsql
set search_path = ''
as $$
begin
  new.definido_em := now();
  new.definido_por := auth.uid();
  return new;
end;
$$;

create trigger carimbo_do_percentual
  before insert on public.percentual_de_comissao
  for each row execute function public.carimbar_percentual_de_comissao();

alter table public.percentual_de_comissao enable row level security;

create policy "coordenacao le" on public.percentual_de_comissao
  for select to authenticated using (public.eh_coordenacao());
create policy "coordenacao define" on public.percentual_de_comissao
  for insert to authenticated with check (public.eh_coordenacao());

revoke all on public.percentual_de_comissao from anon;
grant select, insert on public.percentual_de_comissao to authenticated;

-- Percentual inicial (Nílian, 09/11). Na migração, auth.uid() é nulo.
insert into public.percentual_de_comissao (percentual) values (25.00);

-- ─────────────────────────────────────────
-- 3. A marcação de cada doação. Uma por doação; some com a doação apagada.
--    Teve comissão: com quem captou. Sem comissão: sem ninguém.
-- ─────────────────────────────────────────

create table public.comissoes_de_doacao (
  id            uuid primary key default gen_random_uuid(),
  donation_id   uuid not null unique references public.donations_cash(id) on delete cascade,
  teve_comissao boolean not null,
  captador_id   uuid references public.captadores(id) on delete restrict,
  percentual    numeric(5,2) check (percentual >= 0 and percentual <= 100),
  definido_em   timestamptz not null default now(),
  definido_por  uuid references public.users(id) on delete set null,
  constraint comissao_com_quem_captou check (
    (teve_comissao and captador_id is not null) or (not teve_comissao and captador_id is null)
  )
);

create index idx_comissoes_captador on public.comissoes_de_doacao (captador_id);

-- Quem e quando vêm do banco, também na correção. O percentual é o em vigor na
-- marcação e não muda depois, nem pela API: para usar o novo, desmarcar e marcar.
create or replace function public.carimbar_comissao()
returns trigger
language plpgsql
set search_path = ''
as $$
begin
  new.definido_em := now();
  new.definido_por := auth.uid();
  if tg_op = 'INSERT' then
    new.percentual := (
      select p.percentual
        from public.percentual_de_comissao p
       order by p.definido_em desc
       limit 1
    );
  else
    new.percentual := old.percentual;
  end if;
  return new;
end;
$$;

-- "carimbo" vem antes de "trilha" na ordem alfabética: a trilha já vê o carimbo.
create trigger carimbo_da_comissao
  before insert or update on public.comissoes_de_doacao
  for each row execute function public.carimbar_comissao();

-- SEC-04: correção e desmarcação entram na trilha.
create trigger trilha_de_auditoria before update or delete on public.comissoes_de_doacao
  for each row execute function public.registrar_na_trilha();

alter table public.comissoes_de_doacao enable row level security;

create policy "coordenacao le" on public.comissoes_de_doacao
  for select to authenticated using (public.eh_coordenacao());
create policy "coordenacao marca" on public.comissoes_de_doacao
  for insert to authenticated with check (public.eh_coordenacao());
create policy "coordenacao corrige" on public.comissoes_de_doacao
  for update to authenticated using (public.eh_coordenacao()) with check (public.eh_coordenacao());
create policy "coordenacao desmarca" on public.comissoes_de_doacao
  for delete to authenticated using (public.eh_coordenacao());

revoke all on public.comissoes_de_doacao from anon;
grant select, insert, update, delete on public.comissoes_de_doacao to authenticated;

-- ─────────────────────────────────────────
-- 4. Marcações com a doação, quem captou e o valor calculado sobre o líquido.
--    security_invoker: só a coordenação recebe linhas, e doação cancelada
--    (US-04b) não aparece. Sem líquido (taxa não cadastrada), valor nulo.
-- ─────────────────────────────────────────

create view public.comissoes_view
with (security_invoker = true) as
select
  k.id,
  k.donation_id,
  k.teve_comissao,
  k.captador_id,
  c.nome as captador_nome,
  k.percentual,
  case
    when k.teve_comissao and d.net_amount is not null and k.percentual is not null
      then round(d.net_amount * k.percentual / 100, 2)
  end as valor,
  k.definido_em,
  d.donated_at,
  d.donor_name,
  d.amount,
  d.net_amount
from public.comissoes_de_doacao k
left join public.captadores c on c.id = k.captador_id
join public.donations_cash d on d.id = k.donation_id;

revoke all on public.comissoes_view from anon;
grant select on public.comissoes_view to authenticated;
```

export async function cadastrarCaptador(fd: FormData): Promise<{ error: string } | void> {
  if (!(await souCoordenacao())) return { error: AVISO_RESTRITO }
  const nome = ((fd.get('nome') as string) || '').replace(/\s+/g, ' ').trim()
  if (nome.length < 2 || nome.length > 80) return { error: 'Informe o nome de quem capta.' }
  try {
    await addCaptador(nome)
  } catch (e) {
    if ((e as { code?: string }).code === '23505') return { error: 'Já existe alguém com este nome.' }
    console.error('cadastrarCaptador error:', e)
    return { error: 'Não foi possível cadastrar.' }
  }
  atualizar()
}

  if (!(await souCoordenacao())) return { error: AVISO_RESTRITO }
  if (!UUID.test(id)) return { error: 'Pessoa não encontrada.' }
  try {
    await setCaptadorAtivo(id, ativo)
  } catch (e) {
    console.error('alterarCaptador error:', e)
    return { error: 'Não foi possível alterar.' }
  }
  atualizar()
}

export async function definirPercentualDeComissao(fd: FormData): Promise<{ error: string } | void> {
  if (!(await souCoordenacao())) return { error: AVISO_RESTRITO }
  const digitado = ((fd.get('percentual') as string) || '').replace('%', '').trim()
  // Só número de verdade, com até duas casas: "25", "25,5", "12.75".
  const percentual = /^\d{1,3}([.,]\d{1,2})?$/.test(digitado) ? Number(digitado.replace(',', '.')) : NaN
  if (!Number.isFinite(percentual) || percentual < 0 || percentual > 100) return { error: 'Informe um percentual de 0 a 100 (por exemplo, 25).' }
  try {
    await addPercentualDeComissao(Math.round(percentual * 100) / 100)
  } catch (e) {
    console.error('definirPercentualDeComissao error:', e)
    return { error: 'Não foi possível alterar o percentual.' }
  }
  atualizar()
}

// No formulário, "captador_id" é o id de quem captou ou "sem" (sem comissão).
export async function marcarComissao(donationId: string, fd: FormData): Promise<{ error: string } | void> {
  if (!(await souCoordenacao())) return { error: AVISO_RESTRITO }
  if (!UUID.test(donationId)) return { error: 'Doação não encontrada.' }
  const escolha = ((fd.get('captador_id') as string) || '').trim()
  if (escolha !== SEM_COMISSAO && !UUID.test(escolha)) return { error: 'Escolha quem captou ou "Sem comissão".' }
  try {
    await setMarcacaoDeComissao(donationId, escolha === SEM_COMISSAO ? null : escolha)
  } catch (e) {
    console.error('marcarComissao error:', e)
    return { error: 'Não foi possível salvar a comissão.' }
  }
  atualizar()
}

export async function desmarcarComissao(donationId: string): Promise<{ error: string } | void> {
  if (!(await souCoordenacao())) return { error: AVISO_RESTRITO }
  if (!UUID.test(donationId)) return { error: 'Doação não encontrada.' }
  try {
    await removeMarcacaoDeComissao(donationId)
  } catch (e) {
    console.error('desmarcarComissao error:', e)
    return { error: 'Não foi possível desmarcar.' }
  }
  atualizar()
}
