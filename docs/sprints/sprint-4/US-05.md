# US-05 · Venda registrada em poucos toques (5 SP)

> Como voluntária do brechó, eu quero registrar uma venda com o mínimo de digitação, para que usar o sistema não atrapalhe o atendimento de quem está no balcão.

**Tipo:** user story · **Épico:** Registro no balcão · **Implementa:** Alissa · **Revisa:** Laís · **Branch:** `us-05-venda-em-poucos-toques` · **Depende de:** nada. A busca de pessoa é a da US-06, que já está na `main`.

## Critérios de aceitação

- [ ] Deve identificar a pessoa por nome ou telefone com resultado enquanto se digita
- [ ] Deve oferecer categorias e valores mais usados em atalho
- [ ] Deve concluir uma venda simples em até 3 toques além da escolha da pessoa
- [ ] Deve permitir venda avulsa, sem pessoa identificada, sem travar o fluxo

## O problema

Hoje, uma venda simples na tela **Nova venda** pede: digitar a categoria, digitar o valor e clicar em **Registrar venda**, além de conferir a forma de pagamento. Mais três coisas atrapalham:

- **Nenhum atalho.** Toda peça é digitada, mesmo a blusa de R$ 10 que sai dez vezes por sábado.
- **O banco fica errado na venda em dinheiro.** A tela abre com **Dinheiro** escolhido (as formas vêm em ordem alfabética), mas guarda por baixo o banco do PIX. Quem registra em dinheiro sem tocar no pagamento grava a venda com o banco "PIX TON".
- **A data vira amanhã depois das 21h.** O campo de data usa o dia em UTC. Às 21h30 de Brasília já é o dia seguinte em UTC, e a venda é gravada com a data de amanhã.

E o rótulo **Cliente \*** sugere que a pessoa é obrigatória, quando a venda avulsa já é aceita.

## Decisões

- **Atalhos com combinação de categoria e valor.** Um toque em "blusa · R$ 10,00" põe a peça inteira na venda. Os atalhos são as 8 combinações que mais se repetem nas últimas 300 peças vendidas.
- **Os atalhos vêm do banco,** pela função `atalhos_da_venda`. Ela é `security definer` porque o balcão só enxerga as vendas lançadas hoje (US-23): de manhã, a lista estaria vazia. Sai só categoria, valor e quantas vezes, sem pessoa, data ou forma de pagamento. A primeira condição é `public.eh_equipe()`.
- **A conta dos 3 toques:** atalho (1) e **Registrar venda** (2). Se a forma de pagamento não for a que já vem marcada, mais um toque (3).
- **Se os atalhos falharem, a venda continua.** A tela carrega sem atalhos e a venda é digitada como hoje.
- **A pessoa já é encontrada enquanto se digita** (US-06). O primeiro critério está atendido; esta story acrescenta a prova no teste.
- **Venda avulsa sem asterisco.** O rótulo vira **Cliente**, com o aviso de que, sem pessoa escolhida, a venda fica como Cliente avulso.
- **Correções que entram junto,** por atrapalharem a venda simples: o banco passa a acompanhar a forma de pagamento desde a abertura da tela, e a data passa a ser o dia de Brasília.

## Parte A · Banco

### A1. Migração nova

Arquivo novo: `supabase/migrations/20261019090000_atalhos_da_venda.sql`.

```sql
-- US-05 · Venda registrada em poucos toques
-- Atalhos com as combinações de categoria e valor mais vendidas.

-- ─────────────────────────────────────────
-- atalhos_da_venda: as combinações de categoria e valor que mais se repetem
-- nas últimas 300 peças vendidas.
--
-- security definer porque o balcão só enxerga as vendas lançadas hoje (US-23),
-- e de manhã a lista estaria vazia. Sai só categoria, valor e quantas vezes:
-- nenhuma pessoa, data ou forma de pagamento. Como a função passa por cima das
-- políticas, a primeira condição é public.eh_equipe(): sem perfil ativo, nada.
-- ─────────────────────────────────────────

create or replace function public.atalhos_da_venda(p_limite int default 8)
returns table (categoria text, valor numeric, vezes int)
language sql
stable
security definer
set search_path = ''
as $$
  with recentes as (
    select lower(btrim(si.category_name)) as categoria, si.amount as valor
    from public.sale_items si
    join public.sales s on s.id = si.sale_id
    where public.eh_equipe()
      and btrim(coalesce(si.category_name, '')) <> ''
    order by s.sold_at desc
    limit 300
  )
  select r.categoria, r.valor, count(*)::int as vezes
  from recentes r
  group by r.categoria, r.valor
  order by count(*) desc, r.categoria, r.valor
  limit least(greatest(coalesce(p_limite, 8), 1), 12)
$$;

revoke execute on function public.atalhos_da_venda(int) from public, anon;
grant  execute on function public.atalhos_da_venda(int) to authenticated;
```

export async function getAtalhosDaVenda(): Promise<AtalhoDaVenda[]> {
  const supabase = await createClient()
  const { data, error } = await supabase.rpc('atalhos_da_venda', { p_limite: 8 })

### D1. `tests/fumaca/venda-em-poucos-toques.spec.ts` (arquivo novo)

```ts
import { expect, test } from '@playwright/test'
import { entrar } from './apoio'

// US-05 · Venda registrada em poucos toques.
test.describe('Fumaça: venda em poucos toques', () => {
  test('venda simples pelo atalho: um toque na peça e um no registrar', async ({ page }) => {
    await entrar(page)
    await page.goto('/brecho/nova-venda')

    const atalho = page.getByTestId('atalho-da-venda').first()
    await expect(atalho, 'nenhum atalho apareceu (o seed rodou?)').toBeVisible()
    const valor = ((await atalho.textContent()) ?? '').split('R$')[1]?.trim()
    expect(valor, 'o atalho deveria mostrar o valor').toBeTruthy()

    await test.step('toque 1: o atalho preenche a peça', async () => {
      await atalho.click()
      await expect(page.getByPlaceholder('0,00').first()).toHaveValue(valor!)
    })

    await test.step('toque 2: registrar, sem escolher pessoa (venda avulsa)', async () => {
      await expect(page.getByText('Sem pessoa escolhida, a venda fica como Cliente avulso.')).toBeVisible()
      await page.getByRole('button', { name: 'Registrar venda' }).click()
      await expect(page).toHaveURL(/\/brecho$/)
      await expect(page.getByText(`R$ ${valor}`).first()).toBeVisible()
    })
  })

  test('a pessoa aparece enquanto se digita', async ({ page }) => {
    await entrar(page)
    await page.goto('/brecho/nova-venda')
    await page.getByLabel('Buscar pessoa').fill('3344')
    await expect(page.getByTestId('resultado-da-busca').getByText('Roberta Lima')).toBeVisible()
  })
})
```
