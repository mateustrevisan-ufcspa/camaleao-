# US-17 · Relatório consolidado do Instituto (5 SP)

> Como coordenadora do Instituto, eu quero ver vendas e todos os tipos de doação no mesmo relatório, para que eu enxergue tudo o que o Instituto arrecadou, e não apenas o brechó.

**Tipo:** user story · **Épico:** Relatório e impacto (pedido A) · **Implementa:** Alissa · **Revisa:** Mateus · **Branch:** `us-17-relatorio-consolidado` · **Depende de:** nada para começar. A Parte D (eventos) precisa da US-12 na `main`. Acrescentada à Sprint 4 no replanejamento de 20/10.

## Critérios de aceitação

- [ ] Deve somar receita de vendas, doações em dinheiro, eventos e campanhas no período
- [ ] Deve mostrar o volume de itens recebidos por categoria
- [ ] Deve trazer o ranking das pessoas que mais contribuíram
- [ ] Deve bater com os totais das telas de venda e de doação

## O problema

A tela **Relatórios** só fala do brechó: receita do ano, evolução mensal, formas de pagamento e as clientes que mais compraram no mês. Doações em dinheiro, itens recebidos, eventos e campanhas não aparecem, e não dá para escolher o período.

Há também um erro que o quarto critério expõe: o cartão "Total recebido · mês" da tela de doações em dinheiro soma **todas** as doações já registradas, e não as do mês. Com isso, nenhum relatório consegue "bater" com ele.

## Decisões

- **Uma seção nova no topo de Relatórios,** "Instituto · arrecadação no período". As seções que já existem continuam abaixo, sem mudança.
- **O período vai no endereço** (`?de=AAAA-MM-DD&ate=AAAA-MM-DD`), com três atalhos (Este mês, Mês passado, Este ano) e duas datas para escolher. Sem período, vale o mês corrente. A seção é um componente de servidor: atalho é link e as datas vão por um formulário simples, sem JavaScript.
- **Soma:** vendas do brechó e doações em dinheiro. Ingresso de evento (US-12) e doação de campanha (US-13) são doações em dinheiro, então já entram na soma. A parte de cada evento aparece na Parte D; a de cada campanha, com a US-13.
- **Itens por categoria:** quantas doações, quantas peças e quantos quilos, sem valor em reais.
- **Ranking:** as 10 pessoas com ficha que mais contribuíram no período, somando compras e doações em dinheiro. Doação sem ficha entra nos totais, mas não no ranking; a seção avisa.
- **"Bater com as telas":** o total de vendas de "Este mês" é o mesmo do cartão "Mês de ..." do painel do brechó (mesma regra: desde o dia 1 do mês, em Brasília). E o cartão "Total recebido · mês" da tela de doações passa a somar só as doações do mês, como o rótulo já dizia. Os outros dois cartões dessa tela ("Receita recorrente / mês" e "Total de doadores") também somam tudo e ficam anotados como item novo do backlog.
- **Sem migração.** A tela já é só da coordenação, que enxerga todas as vendas e doações.

## Como este guia mostra as mudanças

Arquivo novo vem inteiro. Em arquivo que já existe, o bloco mostra só o trecho: linha com `-` sai, linha com `+` entra, e as outras são contexto para achar o lugar.

**O código deste guia foi conferido em 20/10** num ambiente de conferência, com a `main` de 20/10 e as stories anteriores desta leva aplicadas: passou em `tsc`, no `npm run lint` e no `next build`, e os números de junho do seed foram conferidos no banco. Os testes do Playwright não foram executados. Quem implementa roda tudo de novo.

### A3. `lib/store.ts`: a função

Logo **depois** de `getReportData` (e antes de `addDonation`). Ela usa `brMidnightUtc`, `DAY_MS` e `round2`, que já existem no arquivo.

```ts
// ── RELATÓRIO CONSOLIDADO DO INSTITUTO (US-17) ──
// Tudo o que o Instituto arrecadou entre duas datas, inclusive, no horário de
// Brasília: vendas do brechó e doações em dinheiro (com os ingressos de evento e
// as doações de campanha, que também são doações em dinheiro), os itens recebidos
// por categoria e as pessoas que mais contribuíram. A tela é só da coordenação,
// que enxerga todas as vendas e doações (US-23).
const TAMANHO_DO_RANKING = 10

export async function getRelatorioConsolidado(inicio: string, fim: string): Promise<RelatorioConsolidado> {
  const [yi, mi, di] = inicio.split('-').map(Number)
  const [yf, mf, df] = fim.split('-').map(Number)
  const desde = brMidnightUtc(yi, mi, di).toISOString()
  const ate = new Date(brMidnightUtc(yf, mf, df).getTime() + DAY_MS).toISOString()

  const supabase = await createClient()
  const [vendas, dinheiro, itens] = await Promise.all([
    supabase.from('sales_view').select('client_id, amount').gte('sold_at', desde).lt('sold_at', ate),
    supabase.from('donations_cash').select('client_id, amount').gte('donated_at', desde).lt('donated_at', ate),
    supabase.from('donations_items').select('category_name, quantity, weight_kg').gte('donated_at', desde).lt('donated_at', ate),
  ])
  const erro = vendas.error ?? dinheiro.error ?? itens.error
  if (erro) throw new Error(erro.message)

  const soma = (linhas: { amount: number | string }[]) => round2(linhas.reduce((s, l) => s + Number(l.amount), 0))
  const totalVendas = { quantidade: (vendas.data ?? []).length, valor: soma(vendas.data ?? []) }
  const totalDoacoes = { quantidade: (dinheiro.data ?? []).length, valor: soma(dinheiro.data ?? []) }

  // Itens recebidos por categoria: quantas doações, quantas peças e quantos quilos.
  const porCategoria = new Map<string, { doacoes: number; quantidade: number; peso: number }>()
  for (const i of itens.data ?? []) {
    const c = porCategoria.get(i.category_name) ?? { doacoes: 0, quantidade: 0, peso: 0 }
    c.doacoes += 1
    c.quantidade += i.quantity ?? 0
    c.peso += Number(i.weight_kg ?? 0)
    porCategoria.set(i.category_name, c)
  }

  // Ranking: compras e doações em dinheiro de quem tem ficha.
  const porPessoa = new Map<string, { compras: number; doacoes: number }>()
  for (const v of vendas.data ?? []) {
    if (!v.client_id) continue
    const p = porPessoa.get(v.client_id) ?? { compras: 0, doacoes: 0 }
    p.compras += Number(v.amount)
    porPessoa.set(v.client_id, p)
  }
  for (const d of dinheiro.data ?? []) {
    if (!d.client_id) continue
    const p = porPessoa.get(d.client_id) ?? { compras: 0, doacoes: 0 }
    p.doacoes += Number(d.amount)
    porPessoa.set(d.client_id, p)
  }
  const primeiros = [...porPessoa]
    .map(([id, p]) => ({ id, compras: round2(p.compras), doacoes: round2(p.doacoes), total: round2(p.compras + p.doacoes) }))
    .sort((a, b) => b.total - a.total)
    .slice(0, TAMANHO_DO_RANKING)

  let nomes = new Map<string, string>()
  if (primeiros.length > 0) {
    const { data: pessoas, error: erroNomes } = await supabase
      .from('clients_view')
      .select('id, name')
      .in('id', primeiros.map((p) => p.id))
    if (erroNomes) throw new Error(erroNomes.message)
    nomes = new Map((pessoas ?? []).map((p) => [p.id as string, p.name as string]))
  }

  return {
    inicio,
    fim,
    vendas: totalVendas,
    doacoes: totalDoacoes,
    eventos: [],
    total: round2(totalVendas.valor + totalDoacoes.valor),
    itens: [...porCategoria]
      .map(([categoria, c]) => ({ categoria, doacoes: c.doacoes, quantidade: c.quantidade, peso: round2(c.peso) }))
      .sort((a, b) => b.doacoes - a.doacoes || a.categoria.localeCompare(b.categoria, 'pt-BR')),
    ranking: primeiros.map((p) => ({ ...p, nome: nomes.get(p.id) ?? 'ficha apagada' })),
  }
}
```
