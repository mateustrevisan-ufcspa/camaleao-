# US-22 · Aniversariantes do mês (1 SP)

> Como coordenadora do Instituto, eu quero ver quem faz aniversário no mês e enviar uma mensagem em um clique, para que o contato afetivo com quem sustenta o Instituto não dependa da minha memória.

**Tipo:** user story · **Épico:** Reconhecimento (pedido L) · **Implementa:** Bibiana · **Revisa:** Mateus · **Branch:** `us-22-aniversariantes-do-mes` · **Depende de:** nada. Acrescentada à Sprint 4 no replanejamento de 20/10.

## Critérios de aceitação

- [ ] Deve listar as pessoas com aniversário no mês escolhido
- [ ] Deve mostrar nome, dia e canal de contato disponível
- [ ] Deve oferecer envio da mensagem em um clique, respeitando o consentimento

## O problema

O painel do brechó já mostra um cartão "Aniversariantes de Outubro", só com nome e data, e só do mês corrente. Não dá para olhar o mês seguinte, não diz como falar com a pessoa e não ajuda a mandar a mensagem. A coordenação depende da memória, que é o que o pedido L quer evitar.

## Decisões

- **Tela nova `/clientes/aniversariantes`, só da coordenação.** O envio usa o telefone inteiro, que só a coordenação recebe desde a SEC-05. A rota entra em `lib/rotas.ts` e o menu ganha "Aniversariantes" no submenu de Clientes.
- **O mês é escolhido por botões** (Jan a Dez). Sem mês na URL, a tela abre no mês de hoje, em Brasília.
- **"Em um clique" é um link que abre o WhatsApp ou o e-mail com a mensagem pronta.** Não há envio automático nem integração: quem clica manda pelo próprio WhatsApp ou e-mail, e o número do Instituto não entra no sistema. O envio automático é da US-21.
- **O consentimento vem da trava da US-07:** só quem está na view `message_recipients` (autorizou e não retirou) ganha os botões. Quem não autorizou aparece na lista, com "Sem autorização de mensagens".
- **O texto da mensagem é uma proposta da equipe,** em `lib/mensagens.ts`. A Flávia pode trocar; é uma linha.
- **Os links ficam em funções separadas** (`lib/mensagens.ts`), para a US-21 reaproveitar.
- **Sem migração.** O aniversário já está na ficha (`dd/mm`, sem o ano) e a autorização já está no banco.
- **O cartão do painel ganha "Ver todos →"** para a coordenação.

### A3. `lib/store.ts`: a função

Logo **depois** de `getBirthdaysThisMonth` (e antes de `getTopCustomerInsight`):

```ts
// ── ANIVERSARIANTES DO MÊS (US-22) ──
// Quem faz aniversário no mês escolhido, com o contato e a autorização de
// mensagens. A tela é só da coordenação, que recebe o telefone inteiro (SEC-05).
export async function getAniversariantes(mes: number): Promise<Aniversariante[]> {
  const supabase = await createClient()
  const { data, error } = await supabase
    .from('clients_view')
    .select('id, name, phone, email, birthday')
    .not('birthday', 'is', null)
    .neq('birthday', '')
  if (error) throw new Error(error.message)

  // O aniversário é guardado como "dd/mm", sem o ano.
  const doMes = (data ?? [])
    .map((c) => {
      const [dia, m] = (c.birthday ?? '').split('/').map(Number)
      return { ...c, dia, m }
    })
    .filter((c) => c.m === mes && c.dia >= 1 && c.dia <= 31)
  if (doMes.length === 0) return []

  // A trava de envio da US-07: só quem está em message_recipients pode receber.
  const { data: autorizadas, error: erroAutorizadas } = await supabase
    .from('message_recipients')
    .select('client_id')
    .in('client_id', doMes.map((c) => c.id))
  if (erroAutorizadas) throw new Error(erroAutorizadas.message)
  const podem = new Set((autorizadas ?? []).map((a) => a.client_id as string))

  return doMes
    .map((c) => ({
      id: c.id,
      name: c.name,
      dia: c.dia,
      phone: c.phone ?? '',
      email: c.email ?? '',
      autorizou: podem.has(c.id),
    }))
    .sort((a, b) => a.dia - b.dia || a.name.localeCompare(b.name, 'pt-BR'))
}
```

### A4. `lib/mensagens.ts` (arquivo novo)

```ts
// Mensagens que a equipe envia pelo próprio WhatsApp ou e-mail, com o texto pronto
// (US-22). Quem decide se a pessoa pode receber é a trava da US-07: a lista
// message_recipients. Estas funções só montam o link.

// O WhatsApp quer só dígitos, com o código do país. Telefone brasileiro com DDD
// tem 10 ou 11 dígitos; sem DDD não dá para montar o link.
export function numeroParaWhatsApp(telefone: string): string | null {
  const digitos = (telefone ?? '').replace(/\D/g, '')
  if (digitos.length === 10 || digitos.length === 11) return `55${digitos}`
  if ((digitos.length === 12 || digitos.length === 13) && digitos.startsWith('55')) return digitos
  return null
}

export function linkDoWhatsApp(telefone: string, texto: string): string | null {
  const numero = numeroParaWhatsApp(telefone)
  return numero ? `https://wa.me/${numero}?text=${encodeURIComponent(texto)}` : null
}

export function linkDoEmail(email: string, assunto: string, texto: string): string | null {
  if (!/^[^\s@]+@[^\s@]+\.[^\s@]+$/.test(email ?? '')) return null
  return `mailto:${email}?subject=${encodeURIComponent(assunto)}&body=${encodeURIComponent(texto)}`
}

// Texto proposto pela equipe; a coordenação do Instituto pode trocar.
export function textoDeAniversario(nome: string): string {
  const primeiroNome = nome.trim().split(/\s+/)[0] ?? ''
  return `Feliz aniversário, ${primeiroNome}! O Instituto Camaleão agradece por você fazer parte da nossa história. Um abraço de toda a equipe.`
}
```

```tsx
import Link from 'next/link'
import { Mail, MessageCircle } from 'lucide-react'
import { getAniversariantes } from '@/lib/store'
import { linkDoEmail, linkDoWhatsApp, numeroParaWhatsApp, textoDeAniversario } from '@/lib/mensagens'
import type { Aniversariante } from '@/types'

export const dynamic = 'force-dynamic'

const MESES = [
  'Janeiro', 'Fevereiro', 'Março', 'Abril', 'Maio', 'Junho',
  'Julho', 'Agosto', 'Setembro', 'Outubro', 'Novembro', 'Dezembro',
]

// Mês de hoje em Brasília: o servidor roda em UTC.
function mesAtual(): number {
  return Number(new Intl.DateTimeFormat('en-US', { timeZone: 'America/Sao_Paulo', month: 'numeric' }).format(new Date()))
}

function canais(p: Aniversariante): string {
  const lista = [numeroParaWhatsApp(p.phone) ? 'WhatsApp' : '', linkDoEmail(p.email, '', '') ? 'e-mail' : ''].filter(Boolean)
  return lista.length > 0 ? lista.join(' e ') : 'sem contato registrado'
}

export default async function AniversariantesPage({
  searchParams,
}: {
  searchParams: Promise<{ mes?: string }>
}) {
  const { mes: mesPedido } = await searchParams
  const pedido = Number(mesPedido)
  const mes = Number.isInteger(pedido) && pedido >= 1 && pedido <= 12 ? pedido : mesAtual()
  const pessoas = await getAniversariantes(mes)

  return (
    <div className="px-4 py-6 md:px-14 md:py-10 max-w-[1000px]">
      <header className="mb-8">
        <div className="text-xs text-muted font-body tracking-[2px] uppercase mb-2">Clientes · Aniversariantes</div>
        <h1 className="font-display text-[28px] md:text-[40px] text-ink font-semibold tracking-[-1px] m-0 leading-[1.1]">
          Aniversariantes de {MESES[mes - 1]}
        </h1>
        <p className="font-body text-muted text-sm mt-2 max-w-[600px]">
          O botão abre o WhatsApp ou o e-mail com a mensagem pronta. Só aparece para quem autorizou receber mensagens do Instituto.
        </p>
      </header>

      <nav aria-label="Mês" className="flex flex-wrap gap-2 mb-6">
        {MESES.map((nome, i) => (
          <Link
            key={nome}
            href={`/clientes/aniversariantes?mes=${i + 1}`}
            aria-current={i + 1 === mes ? 'page' : undefined}
            className={`chip no-underline transition-colors ${
              i + 1 === mes ? 'bg-ink text-bg border-ink' : 'bg-paper text-muted border-rule'
            }`}
          >
            {nome.slice(0, 3)}
          </Link>
        ))}
      </nav>

      {pessoas.length === 0 ? (
        <div className="bg-paper border border-rule rounded-[16px] p-10 text-center font-body text-sm text-muted">
          Ninguém faz aniversário em {MESES[mes - 1].toLowerCase()}.
        </div>
      ) : (
        <ul data-testid="aniversariantes" className="m-0 p-0 list-none bg-paper border border-rule rounded-[16px] overflow-hidden">
          {pessoas.map((p) => {
            const texto = textoDeAniversario(p.name)
            const whatsapp = linkDoWhatsApp(p.phone, texto)
            const email = linkDoEmail(p.email, 'Feliz aniversário!', texto)
            return (
              <li
                key={p.id}
                data-testid="aniversariante"
                className="px-6 py-4 border-b border-rule last:border-0 flex flex-wrap items-center justify-between gap-3"
              >
                <div className="flex items-center gap-4">
                  <span className="font-display text-[22px] text-coral w-9 text-center shrink-0">
                    {String(p.dia).padStart(2, '0')}
                  </span>
                  <div>
                    <div data-testid="nome" className="font-body text-sm text-ink font-medium">{p.name}</div>
                    <div className="font-body text-xs text-muted mt-0.5">{canais(p)}</div>
                  </div>
                </div>
                {!p.autorizou ? (
                  <span className="font-body text-xs text-muted">Sem autorização de mensagens</span>
                ) : !whatsapp && !email ? (
                  <span className="font-body text-xs text-muted">Autorizou, mas não tem contato registrado</span>
                ) : (
                  <div className="flex gap-2">
                    {whatsapp && (
                      <a href={whatsapp} target="_blank" rel="noopener noreferrer" className="chip bg-bg no-underline">
                        <MessageCircle size={11} /> WhatsApp
                      </a>
                    )}
                    {email && (
                      <a href={email} className="chip bg-bg no-underline">
                        <Mail size={11} /> E-mail
                      </a>
                    )}
                  </div>
                )}
              </li>
            )
          })}
        </ul>
      )}
    </div>
  )
}
```

```ts
import { expect, test, type Page } from '@playwright/test'

// US-22 · Aniversariantes do mês.

// Cadastra uma pessoa com aniversário em 31/12 e telefone com DDD.
async function cadastrar(page: Page, nome: string, autoriza: boolean) {
  await page.goto('/clientes')
  await page.getByRole('button', { name: 'Novo cliente' }).click()
  await page.locator('input[name="name"]').fill(nome)
  await page.locator('input[name="phone"]').fill('(51) 99700-2233')

  await page.getByRole('button', { name: 'Cadastrar', exact: true }).click()
  await expect(page.getByRole('heading', { name: nome })).toBeVisible()
}

test.describe('Fumaça: aniversariantes do mês', () => {
  test('o mês escolhido vem em ordem de dia', async ({ page }) => {
    await entrar(page)
    await page.goto('/clientes/aniversariantes?mes=6')
    await expect(page.getByRole('heading', { name: 'Aniversariantes de Junho' })).toBeVisible()

    // Do seed: Mariana 02/06, Patrícia 09/06, Antônia 12/06, Roberta 14/06 e Sônia 17/06.
```
