# US-18 · Exportação dos relatórios em planilha (2 SP)

> Como coordenadora do Instituto, eu quero baixar os relatórios em planilha, para que eu envie os números para a contabilidade sem redigitar nada.

**Tipo:** user story · **Épico:** Relatório e impacto · **Implementa:** Alissa · **Revisa:** Bibiana · **Branch:** `us-18-exportacao-em-planilha` · **Depende de:** US-17 integrada (a seção e a função do relatório consolidado), US-12 integrada (o nome do evento na view de doações) e US-14 integrada (o ajudante `doacaoSemFicha` do teste). Acrescentada à Sprint 4 no replanejamento de 20/10.

## Critérios de aceitação

- [ ] Deve exportar o relatório do período em formato de planilha
- [ ] Deve incluir vendas, doações, eventos e campanhas em abas separadas
- [ ] Deve neutralizar células iniciadas por sinal de fórmula, evitando injeção em planilha
- [ ] Deve usar formato de data e valor do padrão brasileiro

## O problema

O relatório consolidado da US-17 aparece na tela, mas a contabilidade recebe os números digitados de novo, um a um. Um arquivo que abre no Excel, no LibreOffice e no Google Planilhas resolve, desde que o conteúdo vindo do cadastro (nome de doador, observação) não vire fórmula ao ser aberto.

## Decisões

- **Arquivo `.xlsx` gerado no servidor,** por uma rota (`/relatorios/exportar?de=...&ate=...`) que devolve o arquivo para baixar. O botão **Exportar planilha** fica na seção da US-17 e usa o mesmo período da tela.
- **Biblioteca `write-excel-file`** (4.1.1), que só escreve planilha: poucas dependências e nenhuma vulnerabilidade conhecida (`npm audit --omit=dev` sem achados em 20/10). A `exceljs` foi descartada: traz 484 pacotes e um alerta moderado. O teste usa a `fflate` (só em desenvolvimento) para abrir o arquivo.
- **Uma aba por assunto:** Resumo (os números da tela), Vendas, Doações em dinheiro, Doações de itens e Eventos. A aba **Campanhas** chega com a US-13, que integra depois desta story e traz o passo no guia dela.
- **Injeção em planilha:** todo texto que começa com `=`, `+`, `-`, `@`, tabulação ou quebra de linha recebe um apóstrofo na frente, e nenhuma célula é gravada como fórmula. Número e data vão como número e data, não como texto.
- **Padrão brasileiro:** data e hora no formato `dd/mm/aaaa hh:mm`, no horário de Brasília (a planilha não tem fuso), e valor como número com o formato `"R$" #,##0.00`. Assim a coluna continua somável e o separador segue o idioma de quem abre.
- **Sem telefone nem e-mail:** a contabilidade não precisa deles, e a planilha sai do sistema.
- **Só a coordenação:** o proxy já devolve o balcão para o brechó (a rota fica dentro de `/relatorios`) e a rota confere de novo com a mesma função das políticas do banco (`eh_coordenacao`), devolvendo 403. Sem migração.

## Como este guia mostra as mudanças

Arquivo novo vem inteiro. Em arquivo que já existe, o bloco mostra só o trecho: linha com `-` sai, linha com `+` entra, e as outras são contexto para achar o lugar.

**O código deste guia foi conferido em 20/10** num ambiente de conferência, com a `main` de 20/10 e as stories anteriores desta leva aplicadas: passou em `tsc`, no `npm run lint` e no `next build`, e uma planilha gerada pela biblioteca foi aberta e conferida com as mesmas verificações do teste (abas, apóstrofo, nenhuma fórmula e os dois formatos). Os testes do Playwright não foram executados. Quem implementa roda tudo de novo.

```ts
// ── EXPORTAÇÃO DO RELATÓRIO EM PLANILHA (US-18) ──
// As vendas e as doações do período, linha a linha, para as abas da planilha.
export async function getDadosDaExportacao(inicio: string, fim: string): Promise<DadosDaExportacao> {
  const [yi, mi, di] = inicio.split('-').map(Number)
  const [yf, mf, df] = fim.split('-').map(Number)
  const desde = brMidnightUtc(yi, mi, di).toISOString()
  const ate = new Date(brMidnightUtc(yf, mf, df).getTime() + DAY_MS).toISOString()

  const supabase = await createClient()
  const [vendas, dinheiro, itens] = await Promise.all([
    supabase
      .from('sales_view')
      .select('sold_at, customer_name, category, amount, payment_method, bank, installments, net_amount')
      .gte('sold_at', desde)
      .lt('sold_at', ate)
      .order('sold_at'),
    supabase
      .from('donations_cash_view')
      .select('donated_at, donor_name, amount, origin, frequency, event_name, notes')
      .gte('donated_at', desde)
      .lt('donated_at', ate)
      .order('donated_at'),
    supabase
      .from('donations_items')
      .select('donated_at, donor_name, category_name, quantity, weight_kg, condition, destination')
      .gte('donated_at', desde)
      .lt('donated_at', ate)
      .order('donated_at'),
  ])
  const erro = vendas.error ?? dinheiro.error ?? itens.error
  if (erro) throw new Error(erro.message)
  return {
    vendas: (vendas.data ?? []) as DadosDaExportacao['vendas'],
    dinheiro: (dinheiro.data ?? []) as DadosDaExportacao['dinheiro'],
    itens: (itens.data ?? []) as DadosDaExportacao['itens'],
  }
}

// Quem está logado é da coordenação e está ativa (a mesma função das políticas).
export async function souCoordenacao(): Promise<boolean> {
  const supabase = await createClient()
  const { data, error } = await supabase.rpc('eh_coordenacao')
  if (error) throw new Error(error.message)
  return data === true
}
```

`souCoordenacao` chama a mesma função `eh_coordenacao` que as políticas do banco usam. Ela já é executável por `authenticated` desde a US-23.

## Parte B · A planilha

### B1. `lib/planilha.ts` (arquivo novo)

As células, no padrão brasileiro e com a neutralização:

```ts
// Células da exportação em planilha (US-18), no padrão brasileiro e protegidas
// contra injeção em planilha.
import type { CellObject, Row } from 'write-excel-file/node'

// Texto que começa com =, +, -, @, tabulação ou quebra de linha pode ser lido
// como fórmula quando a planilha é aberta ou copiada para outra. O apóstrofo na
// frente faz o programa tratar o conteúdo como texto.
export function neutralizar(texto: string | null | undefined): string {
  const t = texto ?? ''
  return /^[=+\-@\t\r\n]/.test(t) ? `'${t}` : t
}

// A planilha não tem fuso: a data e a hora vão como em Brasília (UTC-3, sem
// horário de verão), como nas telas.
function emBrasilia(iso: string): Date {
  return new Date(new Date(iso).getTime() - 3 * 60 * 60 * 1000)
}

export const FORMATO_DATA = 'dd/mm/yyyy'
export const FORMATO_DATA_HORA = 'dd/mm/yyyy hh:mm'
export const FORMATO_REAIS = '"R$" #,##0.00'

export const texto = (v: string | null | undefined): CellObject => ({ value: neutralizar(v), type: String })
export const numero = (v: number | string | null | undefined): CellObject =>
  v === null || v === undefined || v === '' ? { value: '', type: String } : { value: Number(v), type: Number }
export const reais = (v: number | string | null | undefined): CellObject =>
  v === null || v === undefined || v === '' ? { value: '', type: String } : { value: Number(v), type: Number, format: FORMATO_REAIS }
export const dataHora = (iso: string): CellObject => ({ value: emBrasilia(iso), type: Date, format: FORMATO_DATA_HORA })

export const cabecalho = (nomes: string[]): Row => nomes.map((n) => ({ value: n, type: String, fontWeight: 'bold' }))
```

### B2. `app/(admin)/relatorios/exportar/route.ts` (arquivo novo)

A rota que monta as abas e devolve o arquivo:

```ts
import { NextResponse, type NextRequest } from 'next/server'
import writeExcelFile, { type Row } from 'write-excel-file/node'
import { getDadosDaExportacao, getRelatorioConsolidado, souCoordenacao } from '@/lib/store'
import { cabecalho, dataHora, numero, reais, texto } from '@/lib/planilha'

// US-18 · Exportação do relatório em planilha. Gera um .xlsx com uma aba por
// assunto: resumo, vendas, doações em dinheiro, doações de itens e eventos.
// O proxy já devolve o balcão para o brechó (rota de /relatorios); a conferência
// abaixo é a segunda trava.

const DATA = /^\d{4}-\d{2}-\d{2}$/
const PAGAMENTO: Record<string, string> = { pix: 'PIX', credit: 'Crédito', debit: 'Débito', cash: 'Dinheiro' }
const ESTADO = { good: 'Bom', needs_review: 'Revisar' } as const
const DESTINO = { stock: 'Estoque', direct: 'Direto' } as const
const dataBR = (d: string) => d.split('-').reverse().join('/')

export async function GET(request: NextRequest) {
  if (!(await souCoordenacao())) {
    return new NextResponse('Essa área é restrita à coordenação do Instituto.', { status: 403 })
  }

  const de = request.nextUrl.searchParams.get('de') ?? ''
  const ate = request.nextUrl.searchParams.get('ate') ?? ''
  if (!DATA.test(de) || !DATA.test(ate) || de > ate) {
    return new NextResponse('Período inválido.', { status: 400 })
  }

  const [resumo, linhas] = await Promise.all([getRelatorioConsolidado(de, ate), getDadosDaExportacao(de, ate)])

  const abaResumo: Row[] = [
    [texto('Relatório consolidado do Instituto Camaleão')],
    [texto('Período'), texto(`${dataBR(de)} a ${dataBR(ate)}`)],
    [],
    cabecalho(['', 'Quantidade', 'Valor']),
    [texto('Vendas do brechó'), numero(resumo.vendas.quantidade), reais(resumo.vendas.valor)],
    [texto('Doações em dinheiro'), numero(resumo.doacoes.quantidade), reais(resumo.doacoes.valor)],
    ...resumo.eventos.map((ev): Row => [texto(`  das quais no evento ${ev.nome}`), texto(''), reais(ev.valor)]),
    [texto('Total arrecadado'), texto(''), reais(resumo.total)],
    [],
    cabecalho(['Itens recebidos por categoria', 'Doações', 'Peças', 'Peso (kg)']),
    ...resumo.itens.map((i): Row => [texto(i.categoria), numero(i.doacoes), numero(i.quantidade), numero(i.peso)]),
    [],
    cabecalho(['Quem mais contribuiu', 'Compras', 'Doações', 'Total']),
    ...resumo.ranking.map((p): Row => [texto(p.nome), reais(p.compras), reais(p.doacoes), reais(p.total)]),
  ]

  const abaVendas: Row[] = [
    cabecalho(['Data', 'Cliente', 'Peças', 'Valor', 'Pagamento', 'Banco', 'Parcelas', 'Valor líquido']),
    ...linhas.vendas.map((v): Row => [
      dataHora(v.sold_at),
      texto(v.customer_name),
      texto(v.category),
      reais(v.amount),
      texto(PAGAMENTO[v.payment_method] ?? v.payment_method),
      texto(v.bank),
      numero(v.installments),
      reais(v.net_amount),
    ]),
  ]

  const abaDinheiro: Row[] = [
    cabecalho(['Data', 'Doador', 'Valor', 'Origem', 'Frequência', 'Evento', 'Observações']),
    ...linhas.dinheiro.map((d): Row => [
      dataHora(d.donated_at),
      texto(d.donor_name),
      reais(d.amount),
      texto(d.origin),
      texto(d.frequency === 'monthly' ? 'mensal' : 'pontual'),
      texto(d.event_name),
      texto(d.notes),
    ]),
  ]

  const abaItens: Row[] = [
    cabecalho(['Data', 'Doador', 'Categoria', 'Quantidade', 'Peso (kg)', 'Estado', 'Destino']),
    ...linhas.itens.map((i): Row => [
      dataHora(i.donated_at),
      texto(i.donor_name),
      texto(i.category_name),
      numero(i.quantity),
      numero(i.weight_kg),
      texto(i.condition ? ESTADO[i.condition] : ''),
      texto(i.destination ? DESTINO[i.destination] : ''),
    ]),
  ]

  // Eventos: o que cada evento arrecadou no período, a partir das doações em dinheiro.
  const porEvento = new Map<string, { doacoes: number; valor: number }>()
  for (const d of linhas.dinheiro) {
    if (!d.event_name) continue
    const ev = porEvento.get(d.event_name) ?? { doacoes: 0, valor: 0 }
    ev.doacoes += 1
    ev.valor += Number(d.amount)
    porEvento.set(d.event_name, ev)
  }
  const abaEventos: Row[] = [
    cabecalho(['Evento', 'Doações no período', 'Arrecadado no período']),
    ...[...porEvento].map(([nome, ev]): Row => [texto(nome), numero(ev.doacoes), reais(Math.round(ev.valor * 100) / 100)]),
  ]

  const planilha = await writeExcelFile([
    { sheet: 'Resumo', data: abaResumo, columns: [{ width: 34 }, { width: 14 }, { width: 14 }, { width: 14 }] },
    { sheet: 'Vendas', data: abaVendas, stickyRowsCount: 1, columns: [{ width: 17 }, { width: 28 }, { width: 24 }, { width: 13 }, { width: 12 }, { width: 14 }, { width: 9 }, { width: 13 }] },
    { sheet: 'Doações em dinheiro', data: abaDinheiro, stickyRowsCount: 1, columns: [{ width: 17 }, { width: 28 }, { width: 13 }, { width: 14 }, { width: 11 }, { width: 22 }, { width: 30 }] },
    { sheet: 'Doações de itens', data: abaItens, stickyRowsCount: 1, columns: [{ width: 17 }, { width: 28 }, { width: 16 }, { width: 11 }, { width: 10 }, { width: 10 }, { width: 10 }] },
    { sheet: 'Eventos', data: abaEventos, stickyRowsCount: 1, columns: [{ width: 28 }, { width: 18 }, { width: 20 }] },
  ]).toBuffer()

  return new NextResponse(new Uint8Array(planilha), {
    headers: {
      'Content-Type': 'application/vnd.openxmlformats-officedocument.spreadsheetml.sheet',
      'Content-Disposition': `attachment; filename="relatorio-${de}-a-${ate}.xlsx"`,
      'Cache-Control': 'no-store',
    },
  })
}
```

### C1. `tests/fumaca/exportacao-em-planilha.spec.ts` (arquivo novo)

O `.xlsx` é um zip de arquivos XML: o teste baixa a planilha, abre o zip e confere as abas, o texto das células e os formatos.

```ts
import { readFile } from 'node:fs/promises'
import { expect, test } from '@playwright/test'
import { strFromU8, unzipSync } from 'fflate'
import { doacaoSemFicha, entrar, valorUnico } from './apoio'

// US-18 · Exportação dos relatórios em planilha. O .xlsx é um zip de arquivos
// XML: o teste abre o zip e confere as abas e o texto das células.
test.describe('Fumaça: exportação em planilha', () => {
  test('a planilha do período tem uma aba por assunto e neutraliza fórmula', async ({ page }) => {
    const doador = `=1+1 TESTE US-18 ${Date.now()}`
    const valor = valorUnico(18)
    await entrar(page)

    await test.step('registrar uma doação com nome que parece fórmula', async () => {
      await page.goto('/doacoes/dinheiro/nova')
      await doacaoSemFicha(page, doador)
      await page.locator('input[name="amount"]').fill(valor.numero.toFixed(2))
      await page.getByRole('button', { name: 'Registrar doação' }).click()
      await expect(page).toHaveURL(/\/doacoes\/dinheiro$/)
    })

    const arquivo = await test.step('exportar o mês corrente', async () => {
      await page.goto('/relatorios')
      const [download] = await Promise.all([
        page.waitForEvent('download'),
        page.getByRole('link', { name: 'Exportar planilha' }).click(),
      ])
      expect(download.suggestedFilename()).toMatch(/^relatorio-\d{4}-\d{2}-\d{2}-a-\d{4}-\d{2}-\d{2}\.xlsx$/)
      return unzipSync(new Uint8Array(await readFile(await download.path())))
    })

    await test.step('uma aba por assunto', async () => {
      const pasta = strFromU8(arquivo['xl/workbook.xml'])
      for (const aba of ['Resumo', 'Vendas', 'Doações em dinheiro', 'Doações de itens', 'Eventos']) {
        expect(pasta, `faltou a aba ${aba}`).toContain(`name="${aba}"`)
      }
    })

    await test.step('o nome que parecia fórmula vira texto, e não há fórmula na planilha', async () => {
      const xml = Object.entries(arquivo)
        .filter(([nome]) => nome.startsWith('xl/'))
        .map(([, conteudo]) => strFromU8(conteudo))
        .join('\n')
      expect(xml).toContain(`'${doador}`)
      expect(xml).not.toContain('<f>')
    })

    await test.step('datas e valores no padrão brasileiro', async () => {
      const estilos = strFromU8(arquivo['xl/styles.xml'])
      expect(estilos).toContain('formatCode="dd/mm/yyyy hh:mm"')
      expect(estilos).toContain('formatCode="&quot;R$&quot; #,##0.00"')
    })
  })
})
```
