# US-14 · Toda doação vinculada a uma ficha (3 SP)

> Como coordenadora do Instituto, eu quero que dinheiro, itens, eventos e campanhas fiquem ligados à pessoa que contribuiu, para que eu consiga ver tudo o que uma pessoa fez pelo Instituto em um lugar só.

**Tipo:** user story · **Épico:** Contribuição por pessoa · **Implementa:** Alissa · **Revisa:** Bibiana · **Branch:** `us-14-doacao-com-ficha` · **Depende de:** US-11 integrada (o menu "Categorias" e o formulário de item novo). Acrescentada à Sprint 4 no replanejamento de 20/10.

## Critérios de aceitação

- [ ] Deve usar a mesma busca de pessoa em todos os tipos de doação
- [ ] Deve exigir escolha explícita de doação anônima quando não houver pessoa
- [ ] Deve exibir todos os tipos no histórico da ficha
- [ ] Deve manter as doações antigas sem vínculo acessíveis para associação posterior

## O problema

- **Doação sem pessoa sai por esquecimento.** Hoje, se ninguém for escolhido na busca, o formulário mostra os campos de nome e telefone e aceita a doação solta. Não dá para saber se foi anônima de propósito ou se a voluntária só não procurou a pessoa.
- **Doação solta fica solta para sempre.** Não há como, depois, dizer de quem foi. Ela não entra no histórico nem na contribuição da pessoa (US-15).

Os critérios 1 e 3 já estão quase cumpridos: a busca da US-06 está nas doações em dinheiro e de item (desde a US-11, tampinha é item), e a ficha da US-10 mostra compras e os três tipos de doação. Esta story acrescenta os testes que provam isso.

## Decisões

- **Doação sem ficha vira escolha:** sem pessoa escolhida, o campo do doador mostra uma caixa "Doação sem ficha". Os campos de nome e telefone só aparecem depois de marcar, e o formulário leva `sem_ficha=1`.
- **A regra vale no servidor.** `registerDonation` e `registerDonationItem` recusam a doação sem `client_id` e sem `sem_ficha`, com o aviso "Escolha a pessoa ou marque doação sem ficha." A conferência é a primeira linha de cada função, numa função de `lib/doador.ts`.
- **O botão "Anônimo / avulso" sai da busca, só nas doações.** Na venda ele continua: a venda avulsa da US-05 não muda.
- **Tela nova `/doacoes/sem-ficha`, só da coordenação.** Lista as doações em dinheiro e de item sem pessoa (as 200 mais recentes de cada), e cada uma pode ser ligada a uma ficha pela mesma busca. Ligar é alterar a doação, e só a coordenação altera doação (US-23). O balcão só enxerga as doações de hoje.
- **Ligar só preenche `client_id`.** O nome e o telefone gravados na doação não mudam. O telefone copiado na doação já está anotado como ponto em aberto em `docs/privacidade/dados-pessoais.md`.
- **Sem migração.**
- **Testes que registram doação sem pessoa mudam:** passam a marcar "Doação sem ficha" (uma função nova em `tests/fumaca/apoio.ts`).

## Como este guia mostra as mudanças

Arquivo novo vem inteiro. Em arquivo que já existe, o bloco mostra só o trecho: linha com `-` sai, linha com `+` entra, e as outras são contexto para achar o lugar.

**O código deste guia foi conferido em 20/10** num ambiente de conferência, com a `main` de 20/10, a US-11 e a US-12 aplicadas: passou em `tsc` e no `npm run lint`, e a alteração de doação foi tentada no banco como caixa (nenhuma linha) e como coordenação (uma linha). Os testes do Playwright não foram executados. Quem implementa roda tudo de novo.

### B3. `lib/store.ts`: as funções

No **fim do arquivo**, depois de `addMessageConsent`. A função usa a constante `UUID` que a US-10 já criou no arquivo.

```ts
// ── DOAÇÕES SEM FICHA (US-14) ──
// Doações antigas, ou marcadas como sem ficha, que a coordenação pode ligar a uma
// pessoa depois. O balcão só enxerga as doações de hoje e não altera doação (US-23).
const LIMITE_SEM_FICHA = 200

export async function getDoacoesSemFicha(): Promise<DoacaoSemFicha[]> {
  const supabase = await createClient()
  const [dinheiro, itens] = await Promise.all([
    supabase
      .from('donations_cash')
      .select('id, donated_at, donor_name, amount')
      .is('client_id', null)
      .order('donated_at', { ascending: false })
      .limit(LIMITE_SEM_FICHA),
    supabase
      .from('donations_items')
      .select('id, donated_at, donor_name, category_name, quantity, weight_kg')
      .is('client_id', null)
      .order('donated_at', { ascending: false })
      .limit(LIMITE_SEM_FICHA),
  ])
  const erro = dinheiro.error ?? itens.error
  if (erro) throw new Error(erro.message)

  const linhas: DoacaoSemFicha[] = [
    ...(dinheiro.data ?? []).map((d) => ({
      id: d.id,
      tipo: 'dinheiro' as const,
      data: d.donated_at,
      nome: d.donor_name,
      descricao: `R$ ${Number(d.amount).toLocaleString('pt-BR', { minimumFractionDigits: 2, maximumFractionDigits: 2 })}`,
    })),
    ...(itens.data ?? []).map((d) => ({
      id: d.id,
      tipo: 'itens' as const,
      data: d.donated_at,
      nome: d.donor_name,
      descricao: d.quantity
        ? `${d.quantity}× ${d.category_name}`
        : d.weight_kg
          ? `${Number(d.weight_kg).toLocaleString('pt-BR')} kg de ${d.category_name}`
          : d.category_name || 'Doação de itens',
    })),
  ]
  return linhas.sort((a, b) => new Date(b.data).getTime() - new Date(a.data).getTime())
}

// Liga a doação à ficha. Só vale para doação ainda sem ficha. Com a política
// barrando (balcão), o update não dá erro: só não altera nada. Por isso a linha
// alterada volta e é conferida.
export async function linkDonationToClient(tipo: DoacaoSemFicha['tipo'], id: string, clientId: string): Promise<void> {
  if (!UUID.test(id) || !UUID.test(clientId)) throw new Error('Doação ou pessoa inválida.')
  const supabase = await createClient()
  const tabela = tipo === 'dinheiro' ? 'donations_cash' : 'donations_items'
  const { data, error } = await supabase
    .from(tabela)
    .update({ client_id: clientId })
    .eq('id', id)
    .is('client_id', null)
    .select('id')
  if (error) throw new Error(error.message)
  if (!data || data.length === 0) throw new Error('A doação não foi encontrada, já tem ficha ou você não tem permissão.')
}
```

### B4. `actions/vinculo.ts` (arquivo novo)

```ts
'use server'

import { revalidatePath } from 'next/cache'
import { linkDonationToClient } from '@/lib/store'
import type { DoacaoSemFicha } from '@/types'

// US-14: liga uma doação sem ficha a uma pessoa. Só a coordenação consegue (US-23).
export async function ligarDoacao(
  tipo: DoacaoSemFicha['tipo'],
  id: string,
  clientId: string
): Promise<{ ok: true } | { error: string }> {
  if (tipo !== 'dinheiro' && tipo !== 'itens') return { error: 'Tipo de doação inválido.' }
  try {
    await linkDonationToClient(tipo, id, clientId)
  } catch (e) {
    console.error('ligarDoacao error:', e)
    return { error: e instanceof Error && e.message ? e.message : 'Não foi possível ligar a doação. Tente novamente.' }
  }
  revalidatePath('/doacoes/sem-ficha')
  revalidatePath('/clientes')
  return { ok: true }
}
```

```tsx
'use client'

import { useState, useTransition } from 'react'
import { useRouter } from 'next/navigation'
import { Link2 } from 'lucide-react'
import { ClientPicker } from '@/components/clients/client-picker'
import { ligarDoacao } from '@/actions/vinculo'
import type { DoacaoSemFicha, PessoaEncontrada } from '@/types'

interface DbTag { id: string; name: string; color: string; bg_color: string }

const TIPO = { dinheiro: 'Dinheiro', itens: 'Itens' } as const

export function DoacoesSemFicha({ doacoes, tags }: { doacoes: DoacaoSemFicha[]; tags: DbTag[] }) {
  const router = useRouter()
  // Uma linha aberta por vez, com a pessoa escolhida para ela.
  const [aberta, setAberta] = useState<{ id: string; pessoa: PessoaEncontrada | null } | null>(null)
  const [erro, setErro] = useState<string | null>(null)
  const [aviso, setAviso] = useState<string | null>(null)
  const [isPending, startTransition] = useTransition()

  function ligar(d: DoacaoSemFicha, pessoa: PessoaEncontrada) {
    setErro(null)
    startTransition(async () => {
      const res = await ligarDoacao(d.tipo, d.id, pessoa.id)
      if ('error' in res) {
        setErro(res.error)
        return
      }
      setAviso(`Doação de ${d.nome} ligada à ficha de ${pessoa.name}.`)
      setAberta(null)
      router.refresh()
    })
  }

  return (
    <div className="flex flex-col gap-4">
      {aviso && (
        <div className="rounded-[10px] px-4 py-3 font-body text-[13px]" style={{ backgroundColor: '#DCEBE0', color: '#2E5C3E' }}>
          {aviso}
        </div>
      )}
      {erro && (
        <div className="rounded-[10px] px-4 py-3 font-body text-[13px]" style={{ backgroundColor: '#F8DCD2', color: '#D87560' }}>
          {erro}
        </div>
      )}

      {doacoes.length === 0 ? (
        <div className="bg-paper border border-rule rounded-[16px] p-10 text-center font-body text-sm text-muted">
          Todas as doações estão ligadas a uma ficha.
        </div>
      ) : (
        <ul data-testid="doacoes-sem-ficha" className="m-0 p-0 list-none bg-paper border border-rule rounded-[16px] overflow-hidden">
          {doacoes.map((d) => {
            const estaAberta = aberta?.id === d.id
            return (
              <li key={`${d.tipo}-${d.id}`} className="px-6 py-4 border-b border-rule last:border-0">
                <div className="flex flex-wrap items-center justify-between gap-3">
                  <div>
                    <div className="font-body text-sm text-ink font-medium">{d.nome}</div>
                    <div className="font-body text-xs text-muted mt-0.5">
                      {TIPO[d.tipo]} · {d.descricao} ·{' '}
                      {new Date(d.data).toLocaleDateString('pt-BR', { timeZone: 'America/Sao_Paulo' })}
                    </div>
                  </div>
                  {!estaAberta && (
                    <button type="button" onClick={() => setAberta({ id: d.id, pessoa: null })} className="chip bg-bg">
                      <Link2 size={11} /> Ligar a uma ficha
                    </button>
                  )}
                </div>
                {estaAberta && (
                  <div className="mt-4 flex flex-col gap-3">
                    <ClientPicker
                      tags={tags}
                      allowAnonymous={false}
                      selected={aberta.pessoa}
                      onSelect={(p) => setAberta({ id: d.id, pessoa: p })}
                    />
                    <div className="flex gap-2">
                      <button
                        type="button"
                        disabled={!aberta.pessoa || isPending}
                        onClick={() => aberta.pessoa && ligar(d, aberta.pessoa)}
                        className="btn-dark disabled:opacity-50 disabled:cursor-not-allowed"
                      >
                        {isPending ? 'Ligando...' : aberta.pessoa ? `Ligar a ${aberta.pessoa.name}` : 'Escolha a pessoa'}
                      </button>
                      <button type="button" onClick={() => setAberta(null)} className="chip bg-bg">
                        Cancelar
                      </button>
                    </div>
                  </div>
                )}
              </li>
            )
          })}
        </ul>
      )}
    </div>
  )
}
```

```ts
// US-14 · Doação sem ficha: só a coordenação liga uma doação a uma pessoa.
import { test, expect } from '@playwright/test'
import type { SupabaseClient } from '@supabase/supabase-js'
import { CAIXA, COORDENACAO, entrarNaApi } from './apoio'

const MARCA = 'TESTE US-14'

let coordenacao: SupabaseClient
let caixa: SupabaseClient
let doacaoId: string
let pessoaId: string

test.describe.configure({ mode: 'serial' })

test.beforeAll(async () => {
  ;({ api: coordenacao } = await entrarNaApi(COORDENACAO))
  let caixaId: string
  ;({ api: caixa, id: caixaId } = await entrarNaApi(CAIXA))

  const pessoa = await coordenacao.from('clients').insert({ name: MARCA, member_since: 2026 }).select('id').single()
  if (pessoa.error) throw new Error(`Não cadastrou a pessoa do teste: ${pessoa.error.message}`)
  pessoaId = pessoa.data.id

  const doacao = await caixa
    .from('donations_cash')
    .insert({ donor_name: MARCA, amount: 12, frequency: 'one_time', donated_at: new Date().toISOString(), registered_by: caixaId })
    .select('id')
    .single()
  if (doacao.error) throw new Error(`Não registrou a doação do teste: ${doacao.error.message}`)
  doacaoId = doacao.data.id
})

test.afterAll(async () => {
  if (!coordenacao) return
  await coordenacao.from('donations_cash').delete().eq('donor_name', MARCA)
  await coordenacao.from('clients').delete().eq('name', MARCA)
})

test('a caixa não liga a doação a uma ficha', async () => {
  const r = await caixa.from('donations_cash').update({ client_id: pessoaId }).eq('id', doacaoId).select('id')
  expect(r.data ?? []).toHaveLength(0)
  const depois = await coordenacao.from('donations_cash').select('client_id').eq('id', doacaoId).single()
  expect(depois.data?.client_id).toBeNull()
})

test('a coordenação liga a doação, e ela passa a contar na ficha', async () => {
  const r = await coordenacao.from('donations_cash').update({ client_id: pessoaId }).eq('id', doacaoId).is('client_id', null).select('id')
  expect(r.data).toHaveLength(1)
  const ficha = await coordenacao.from('clients_view').select('donation_count, donation_total').eq('id', pessoaId).single()
  expect(ficha.data).toMatchObject({ donation_count: 1 })
  expect(Number(ficha.data!.donation_total)).toBe(12)
})
```
