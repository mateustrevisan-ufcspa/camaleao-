# US-15 · Contribuição total da pessoa no período (8 SP)

> Como coordenadora do Instituto, eu quero ver quanto uma pessoa contribuiu no ano somando compras, doações, eventos e campanhas, para que eu faça um contato personalizado agradecendo o total, e não cada parte separada.

**Tipo:** user story · **Épico:** Contribuição por pessoa (pedido A) · **Implementa:** Mateus · **Revisa:** Alissa · **Branch:** `us-15-contribuicao-no-periodo` · **Depende de:** nada para começar. A Parte D (eventos) entra depois do merge da US-12. Acrescentada à Sprint 4 no replanejamento de 20/10.

## Critérios de aceitação

- [ ] Deve somar compras, doações em dinheiro, eventos e campanhas no período
- [ ] Deve listar as contribuições em itens, com categoria e data
- [ ] Deve exibir o total na ficha da pessoa em menos de um minuto de navegação
- [ ] Deve permitir escolher o período do cálculo

## O problema

É o pedido central da Flávia nas respostas de 03/09: ver, num lugar só, tudo o que uma pessoa fez pelo Instituto, para agradecer o total do ano. A ficha mostra o "Total gasto" no brechó desde sempre e a lista de compras e doações (US-10), mas não soma compras com doações, não deixa escolher o período e não junta os itens doados.

## Decisões

- **Um cartão novo na ficha, "Contribuição no período",** entre o cartão de mensagens e o histórico. Abre em "Este ano", com o total à vista: Clientes, a pessoa, e o total já aparece. São três cliques, bem menos de um minuto.
- **Período:** "Este ano", "Últimos 12 meses", "Ano passado" ou "Escolher datas" (de e até, inclusive). As datas são de Brasília.
- **Soma:** compras no brechó e doações em dinheiro. Ingresso de evento (US-12) e doação de campanha (US-13) também são doações em dinheiro, então já entram na soma. O cartão mostra separada a parte de cada evento (Parte D). A parte de cada campanha fica com a US-13, que integra depois.
- **Itens doados não têm valor em reais:** aparecem numa lista com categoria, quantidade ou peso e data, e não entram no total.
- **Só a coordenação vê o cartão.** Para o balcão, as políticas da US-23 só devolvem o que foi lançado hoje, e a soma sairia errada sem aviso. A ficha recebe `ehCoordenacao`, que a tela Clientes já tem desde a US-08b.
- **Sem migração.** As três consultas passam pelas políticas de quem está logado.
- **Chave própria no cartão** (`contribuicao-${id}`): o achado da Bibiana na US-10 vale aqui. Dois irmãos com a mesma `key` confundem o React.

### A3. `lib/store.ts`: a função

Logo **depois** de `getRegistroOriginal` (e antes de `getReportData`). Ela usa `brMidnightUtc`, `DAY_MS` e `round2`, que já existem no arquivo.

```ts
// ── CONTRIBUIÇÃO DA PESSOA NO PERÍODO (US-15) ──
// Soma o que a pessoa fez pelo Instituto entre duas datas, inclusive, no horário
// de Brasília: compras e doações em dinheiro (com os ingressos de evento e as
// doações de campanha, que também são doações em dinheiro), mais a lista dos
// itens doados. Para o balcão a soma seria só a do que foi lançado hoje (US-23):
// por isso a ficha só mostra o cartão para a coordenação.
export async function getContribuicao(clientId: string, inicio: string, fim: string): Promise<ContribuicaoNoPeriodo> {
  const [yi, mi, di] = inicio.split('-').map(Number)
  const [yf, mf, df] = fim.split('-').map(Number)
  const desde = brMidnightUtc(yi, mi, di).toISOString()
  const ate = new Date(brMidnightUtc(yf, mf, df).getTime() + DAY_MS).toISOString()

  const supabase = await createClient()
  const [vendas, dinheiro, itens] = await Promise.all([
    supabase.from('sales_view').select('amount').eq('client_id', clientId).gte('sold_at', desde).lt('sold_at', ate),
    supabase.from('donations_cash').select('amount').eq('client_id', clientId).gte('donated_at', desde).lt('donated_at', ate),
    supabase
      .from('donations_items')
      .select('donated_at, category_name, quantity, weight_kg')
      .eq('client_id', clientId)
      .gte('donated_at', desde)
      .lt('donated_at', ate)
      .order('donated_at', { ascending: false }),
  ])
  const erro = vendas.error ?? dinheiro.error ?? itens.error
  if (erro) throw new Error(erro.message)

  const soma = (linhas: { amount: number | string }[]) => round2(linhas.reduce((s, l) => s + Number(l.amount), 0))
  const compras = { quantidade: (vendas.data ?? []).length, valor: soma(vendas.data ?? []) }
  const doacoes = { quantidade: (dinheiro.data ?? []).length, valor: soma(dinheiro.data ?? []) }

  return {
    inicio,
    fim,
    compras,
    doacoes,
    eventos: [],
    itens: (itens.data ?? []).map((i) => ({
      data: i.donated_at,
      categoria: i.category_name,
      quantidade: i.quantity,
      peso: i.weight_kg === null ? null : Number(i.weight_kg),
    })),
    total: round2(compras.valor + doacoes.valor),
  }
}
```

type Periodo = 'ano' | '12meses' | 'anoPassado' | 'datas'

const PERIODOS: { valor: Periodo; rotulo: string }[] = [
  { valor: 'ano', rotulo: 'Este ano' },
  { valor: '12meses', rotulo: 'Últimos 12 meses' },
  { valor: 'anoPassado', rotulo: 'Ano passado' },
  { valor: 'datas', rotulo: 'Escolher datas' },
]

const ITENS_POR_VEZ = 10

// "AAAA-MM-DD" de n dias antes de uma data, sem passar por fuso.
function diasAntes(data: string, n: number): string {
  const [y, m, d] = data.split('-').map(Number)
  return new Date(Date.UTC(y, m - 1, d) - n * 24 * 60 * 60 * 1000).toISOString().slice(0, 10)
}

function intervalo(periodo: Periodo, datas: { inicio: string; fim: string }): { inicio: string; fim: string } {
  const hoje = brTodayStr()
  const ano = Number(hoje.slice(0, 4))
  if (periodo === 'ano') return { inicio: `${ano}-01-01`, fim: hoje }
  if (periodo === '12meses') return { inicio: diasAntes(hoje, 364), fim: hoje }
  if (periodo === 'anoPassado') return { inicio: `${ano - 1}-01-01`, fim: `${ano - 1}-12-31` }
  return datas
}

const dataCurta = (iso: string) => new Date(iso).toLocaleDateString('pt-BR', { timeZone: 'America/Sao_Paulo' })

function quanto(i: ContribuicaoNoPeriodo['itens'][number]) {
  const partes = [
    i.quantidade ? `${i.quantidade} un` : '',
    i.peso ? `${i.peso.toLocaleString('pt-BR')} kg` : '',
  ].filter(Boolean)
  return partes.length > 0 ? partes.join(' · ') : 'só o registro'
}

// A ficha monta este cartão com uma key feita do id da pessoa: trocar de pessoa
// recomeça do zero (US-10).
export function ContribuicaoNaFicha({ clientId }: { clientId: string }) {
  const [periodo, setPeriodo] = useState<Periodo>('ano')
  const [datas, setDatas] = useState(() => intervalo('ano', { inicio: '', fim: '' }))
  const [mostrando, setMostrando] = useState(ITENS_POR_VEZ)
  // O resultado guarda o período que o gerou: resposta atrasada de outro período é ignorada.
  const [resultado, setResultado] = useState<{ chave: string; dados: ContribuicaoNoPeriodo | null } | null>(null)

  const { inicio, fim } = intervalo(periodo, datas)
  const valido = /^\d{4}-\d{2}-\d{2}$/.test(inicio) && /^\d{4}-\d{2}-\d{2}$/.test(fim) && inicio <= fim
  const chave = `${inicio}|${fim}`

  useEffect(() => {
    if (!valido) return
    let ativo = true
    fetchContribuicao(clientId, inicio, fim)
      .then((dados) => { if (ativo) setResultado({ chave, dados }) })
      .catch((e) => {
        console.error(e)
        if (ativo) setResultado({ chave, dados: null })
      })
    return () => { ativo = false }
  }, [clientId, inicio, fim, chave, valido])

  const carregando = valido && resultado?.chave !== chave
  const dados = !carregando && resultado?.chave === chave ? resultado.dados : null

  return (
    <div data-testid="contribuicao-no-periodo" className="p-6 border-b border-rule">
      <h4 className="text-[11px] text-muted tracking-[1.5px] uppercase font-body mb-3.5">Contribuição no período</h4>

      <div className="flex flex-wrap gap-2 mb-4">
        {PERIODOS.map((p) => (
          <button
            key={p.valor}
            type="button"
            aria-pressed={periodo === p.valor}
            onClick={() => { setPeriodo(p.valor); setMostrando(ITENS_POR_VEZ) }}
            className={`chip transition-colors ${periodo === p.valor ? 'bg-ink text-bg border-ink' : 'bg-paper text-muted border-rule'}`}
          >
            {p.rotulo}
          </button>
        ))}
      </div>

      {periodo === 'datas' && (
        <div className="grid grid-cols-2 gap-3 mb-4">
          <div>
            <label htmlFor="contribuicao-de" className="block text-[11px] font-body text-muted tracking-[1px] uppercase mb-1.5">De</label>
            <input
              id="contribuicao-de"
              type="date"
              value={datas.inicio}
              max={datas.fim || undefined}
              onChange={(e) => setDatas((d) => ({ ...d, inicio: e.target.value }))}
              className="input-base"
            />
          </div>
          <div>
            <label htmlFor="contribuicao-ate" className="block text-[11px] font-body text-muted tracking-[1px] uppercase mb-1.5">Até</label>
            <input
              id="contribuicao-ate"
              type="date"
              value={datas.fim}
              min={datas.inicio || undefined}
              onChange={(e) => setDatas((d) => ({ ...d, fim: e.target.value }))}
              className="input-base"
            />
          </div>
        </div>
      )}

      {!valido ? (

      ) : carregando ? (
        <div className="text-sm text-muted font-body py-2">Carregando...</div>
      ) : !dados ? (
        <div className="text-sm text-muted font-body py-2">Não foi possível calcular a contribuição.</div>
      ) : (
        <>
          <div className="mb-4">
            <div className="text-[11px] text-muted tracking-[1.5px] uppercase font-body mb-1">
              Total de {dataCurta(`${dados.inicio}T12:00:00-03:00`)} a {dataCurta(`${dados.fim}T12:00:00-03:00`)}
            </div>
            <div data-testid="contribuicao-total" className="font-display text-[32px] text-ink font-semibold tracking-[-0.8px] leading-none">
              R$ {formatBRL(dados.total)}
            </div>
          </div>

          <dl className="m-0 grid grid-cols-[1fr_auto] gap-x-4 gap-y-2 font-body text-[13px]">
            <dt className="text-muted">
              Compras no brechó ({dados.compras.quantidade})

            <dd data-testid="contribuicao-compras" className="m-0 text-ink text-right">R$ {formatBRL(dados.compras.valor)}</dd>
