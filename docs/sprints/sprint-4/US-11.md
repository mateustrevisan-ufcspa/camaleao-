# US-11 · Doação de itens com categorias editáveis (5 SP)

> Como voluntária do brechó, eu quero registrar qualquer item doado escolhendo a categoria, inclusive tampinhas, para que eu anote o que chegou sem depender de uma tela diferente para cada tipo de coisa.

**Tipo:** user story · **Épico:** Doações reorganizadas · **Implementa:** Laís · **Revisa:** Bibiana · **Branch:** `us-11-categorias-de-doacao` · **Depende de:** nada. A US-12, também da Laís, vem depois e mexe nos mesmos arquivos de doação.

## Critérios de aceitação

- [ ] Deve permitir cadastrar e editar categorias de item pela interface, sem alterar o código
- [ ] Deve incluir tampinhas, lenço, peruca, batom e roupas entre as categorias
- [ ] Deve tornar quantidade e peso opcionais, aceitando o registro apenas do que foi trazido
- [ ] Deve migrar os registros de tampinhas existentes para a nova categoria, sem perder o doador
- [ ] Deve remover a tela separada de tampinhas do menu

## O problema

- **As categorias só mudam no código ou no banco.** Não há tela para cadastrar "peruca" ou "batom", que o Instituto pediu em 03/09.
- **Tampinhas têm tela, formulário, lista e tabela próprios** (`donations_caps`), e exigem quantidade ou peso. O Instituto disse que não pesa: quer só registrar que a pessoa trouxe.
- **A doação de item exige quantidade,** e o campo de categoria aceita qualquer texto, o que cria categorias soltas ("Blusa", "blusas", "blusa ").

## Decisões

- **Tela de categorias só da coordenação,** em `/doacoes/categorias` (a rota já está em `lib/rotas.ts`). Cadastra, renomeia, muda onde a categoria é usada (venda, doação ou as duas) e desativa. Não apaga: categoria desativada sai dos formulários e continua nos registros antigos. A política "admin write" da tabela já existe; o banco não muda nesse ponto.
- **Nome da categoria em minúsculas,** como as que já existem. Renomear não muda as doações já registradas, que guardam o nome da época.
- **No formulário de item, a categoria passa a ser escolhida numa lista,** só com as categorias ativas de doação. O nome gravado vem do banco, e não do navegador.
- **Quantidade e peso opcionais.** A doação pode ter só a categoria e quem trouxe. Coluna nova `donations_items.weight_kg`.
- **Estado e destino somem para tampinha.** Não fazem sentido para tampinha, e o registro fica vazio nesses dois campos.
- **As tampinhas viram doação de item da categoria "tampinha"** na migração, com o mesmo id, a mesma pessoa, as mesmas datas e quem registrou. O id igual importa para a US-08b: quem desfizer uma mesclagem anterior a esta migração encontra as tampinhas.
- **A tabela `donations_caps` fica congelada e vazia:** sem escrita pela API. Apagar a tabela mexeria na `clients_view`, na busca da US-06 e na mesclagem da US-08b ao mesmo tempo; fica para uma technical story depois desta sprint, junto com as duas funções dela em `lib/store.ts` e o tipo `DonationCaps`, que **não** são apagados agora.
- **As telas antigas de tampinhas redirecionam:** `/doacoes/tampinhas` vai para a lista de itens, e `/doacoes/tampinhas/nova` vai para a nova doação de item com "tampinha" já escolhida.

export async function getAllItemCategories(): Promise<CategoriaDeItem[]> {
  const supabase = await createClient()
  const { data, error } = await supabase.from('item_categories').select('id, name, type, active').order('name')
  if (error) throw new Error(error.message)
  return (data ?? []) as CategoriaDeItem[]

// Uma categoria ativa de doação, para gravar o nome que está no banco.
export async function getDonationCategory(id: string): Promise<{ id: string; name: string } | null> {
  const supabase = await createClient()
  const { data, error } = await supabase
    .from('item_categories')
    .select('id, name')
    .eq('id', id)
    .eq('active', true)
    .in('type', ['donation', 'both'])
    .maybeSingle()
  if (error) throw new Error(error.message)
  return data
}

export async function addItemCategory(name: string, type: CategoriaDeItem['type']): Promise<void> {
  const supabase = await createClient()
  const { error } = await supabase.from('item_categories').insert({ name, type })
  if (error) throw new Error(error.message)
}

export async function updateItemCategory(
  id: string,
  campos: { name: string; type: CategoriaDeItem['type']; active: boolean }
): Promise<void> {
  const supabase = await createClient()
  // Com a política barrando, o update não dá erro: só não altera nada. Por isso
  // a linha alterada volta e é conferida.
  const { data, error } = await supabase.from('item_categories').update(campos).eq('id', id).select('id')
  if (error) throw new Error(error.message)
  if (!data || data.length === 0) throw new Error('Categoria não encontrada ou sem permissão para alterar.')
}

### D2. `actions/categorias.ts` (arquivo novo)

```ts
'use server'

import { revalidatePath } from 'next/cache'
import { addItemCategory, updateItemCategory } from '@/lib/store'

const TIPOS = ['sale', 'donation', 'both'] as const
type Tipo = (typeof TIPOS)[number]

function lerCampos(fd: FormData): { name: string; type: Tipo } | { error: string } {
  const name = ((fd.get('name') as string) || '').trim().toLowerCase()
  const type = (fd.get('type') as string) || ''
  if (!name) return { error: 'Informe o nome da categoria.' }
  if (name.length > 40) return { error: 'Use um nome de até 40 letras.' }
  if (!TIPOS.includes(type as Tipo)) return { error: 'Escolha onde a categoria é usada.' }
  return { name, type: type as Tipo }
}

function mensagem(e: unknown) {
  const texto = e instanceof Error ? e.message : ''
  if (texto.includes('duplicate key') || texto.includes('unique')) return 'Já existe uma categoria com esse nome.'
  return 'Não foi possível salvar a categoria. Tente novamente.'
}

function revalidarTelas() {
  revalidatePath('/doacoes/categorias')
  revalidatePath('/doacoes/itens/nova')
  revalidatePath('/brecho/nova-venda')
}

export async function criarCategoria(fd: FormData): Promise<{ error: string } | void> {
  const campos = lerCampos(fd)
  if ('error' in campos) return campos
  try {
    await addItemCategory(campos.name, campos.type)
  } catch (e) {
    console.error('criarCategoria error:', e)
    return { error: mensagem(e) }
  }
  revalidarTelas()
}

export async function salvarCategoria(fd: FormData): Promise<{ error: string } | void> {
  const id = ((fd.get('id') as string) || '').trim()
  const campos = lerCampos(fd)
  if ('error' in campos) return campos
  try {
    await updateItemCategory(id, { ...campos, active: fd.get('active') === 'on' })
  } catch (e) {
    console.error('salvarCategoria error:', e)
    return { error: mensagem(e) }
  }
  revalidarTelas()
}
```
