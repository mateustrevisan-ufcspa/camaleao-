# US-20 · Acompanhamento de doadores recorrentes (3 SP)

> Como coordenadora do Instituto, eu quero ver quem doa todo mês e perceber quando alguém para, para que o Instituto reconheça a recorrência e aja a tempo quando ela é interrompida.

**Tipo:** user story · **Épico:** Reconhecimento (pedido M) · **Implementa:** Bibiana · **Revisa:** Laís · **Branch:** `us-20-doadores-recorrentes` · **Depende de:** US-22 integrada (o submenu de Clientes com "Aniversariantes"). Acrescentada à Sprint 4 no replanejamento de 20/10.

## Critérios de aceitação

- [ ] Deve listar as pessoas marcadas como doadoras mensais
- [ ] Deve indicar a data da última doação de cada uma
- [ ] Deve destacar quem está há mais de 45 dias sem doar
- [ ] Deve permitir filtrar apenas os interrompidos

## O problema

A doação em dinheiro já tem a frequência "Mensal" desde a versão original, mas nenhuma tela usa isso. Quem doa todo mês e para de doar só é percebido se alguém lembrar.

## Decisões

- **"Doadora mensal" é quem tem ao menos uma doação em dinheiro marcada como "Mensal".** Não há campo novo na ficha: a marcação já é feita na doação.
- **"Última doação" é a doação em dinheiro mais recente da pessoa,** de qualquer frequência. O valor mensal mostrado é o da doação mensal mais recente.
- **Interrompido é mais de 45 dias sem doar,** contados em dias de calendário de Brasília. Os 45 dias ficam numa constante (`DIAS_PARA_INTERROMPIDO`), para a coordenação poder mudar.
- **Tela nova `/clientes/recorrentes`, só da coordenação,** com o filtro "Só interrompidos" no endereço (`?filtro=interrompidos`). Quem está há mais tempo sem doar aparece primeiro. A rota entra em `lib/rotas.ts` e o menu ganha "Doadores recorrentes" no submenu de Clientes.
- **Só pessoas com ficha.** Doação mensal sem ficha (a "Empresa Helmuth Ltda" do seed) não aparece na lista; a tela avisa quantas são e aponta para Doações · Sem ficha (US-14), onde podem ser ligadas a uma pessoa.
- **Sem migração.** A soma é feita em `lib/store.ts`, sobre as doações que a coordenação já enxerga.

## Como este guia mostra as mudanças

Arquivo novo vem inteiro. Em arquivo que já existe, o bloco mostra só o trecho: linha com `-` sai, linha com `+` entra, e as outras são contexto para achar o lugar.

**O código deste guia foi conferido em 20/10** num ambiente de conferência, com a `main` de 20/10 e as stories anteriores desta leva aplicadas: passou em `tsc` e no `npm run lint`, e as doações mensais do seed foram conferidas no banco. Os testes do Playwright não foram executados. Quem implementa roda tudo de novo.

### A3. `lib/store.ts`: a função

Logo **depois** de `getDonations` (e antes de `getPaymentMethods`). Ela usa `brNowParts`, `DAY_MS` e `round2`, que já existem no arquivo.

```ts
// ── DOADORES RECORRENTES (US-20) ──
// Quem tem ao menos uma doação em dinheiro marcada como mensal, com a última
// doação (de qualquer frequência) e há quantos dias foi. Mais de 45 dias sem
// doar conta como interrompido. Só a coordenação enxerga o histórico inteiro
// (US-23): a tela é só dela.
export const DIAS_PARA_INTERROMPIDO = 45

// Dias de calendário, em Brasília, entre a data da doação e hoje.
function diasDesde(iso: string): number {
  const { y, m, d } = brNowParts()
  const [yd, md, dd] = new Intl.DateTimeFormat('en-CA', {
    timeZone: 'America/Sao_Paulo', year: 'numeric', month: '2-digit', day: '2-digit',
  }).format(new Date(iso)).split('-').map(Number)
  return Math.round((Date.UTC(y, m - 1, d) - Date.UTC(yd, md - 1, dd)) / DAY_MS)
}

export async function getDoadoresRecorrentes(): Promise<{ doadores: DoadorRecorrente[]; mensaisSemFicha: number }> {
  const supabase = await createClient()
  const [doacoes, semFicha] = await Promise.all([
    supabase
      .from('donations_cash')
      .select('client_id, amount, frequency, donated_at')
      .not('client_id', 'is', null)
      .order('donated_at', { ascending: false }),
    supabase
      .from('donations_cash')
      .select('id', { count: 'exact', head: true })
      .is('client_id', null)
      .eq('frequency', 'monthly'),
  ])
  if (doacoes.error) throw new Error(doacoes.error.message)
  if (semFicha.error) throw new Error(semFicha.error.message)

  // As doações vêm da mais recente para a mais antiga: a primeira de cada pessoa
  // é a última doação, e a primeira mensal dá o valor mensal.
  const porPessoa = new Map<string, { ultima: string; valorMensal: number | null }>()
  for (const d of doacoes.data ?? []) {
    const id = d.client_id as string
    const atual = porPessoa.get(id) ?? { ultima: d.donated_at, valorMensal: null }
    if (atual.valorMensal === null && d.frequency === 'monthly') atual.valorMensal = Number(d.amount)
    porPessoa.set(id, atual)
  }
  const mensais = [...porPessoa].filter(([, p]) => p.valorMensal !== null)
  if (mensais.length === 0) return { doadores: [], mensaisSemFicha: semFicha.count ?? 0 }

  const { data: pessoas, error } = await supabase
    .from('clients_view')
    .select('id, name')
    .in('id', mensais.map(([id]) => id))
  if (error) throw new Error(error.message)
  const nomes = new Map((pessoas ?? []).map((p) => [p.id as string, p.name as string]))

  const doadores = mensais
    .filter(([id]) => nomes.has(id))
    .map(([id, p]) => {
      const dias = diasDesde(p.ultima)
      return {
        id,
        name: nomes.get(id)!,
        valorMensal: round2(p.valorMensal ?? 0),
        ultimaDoacao: p.ultima,
        diasSemDoar: dias,
        interrompido: dias > DIAS_PARA_INTERROMPIDO,
      }
    })
    .sort((a, b) => b.diasSemDoar - a.diasSemDoar || a.name.localeCompare(b.name, 'pt-BR'))
  return { doadores, mensaisSemFicha: semFicha.count ?? 0 }
}
```

## Parte B · Tela

### B1. `app/(admin)/clientes/recorrentes/page.tsx` (arquivo novo)

```tsx
import Link from 'next/link'
import { DIAS_PARA_INTERROMPIDO, getDoadoresRecorrentes } from '@/lib/store'
import { formatBRL } from '@/lib/utils'

export const dynamic = 'force-dynamic'

const dataCurta = (iso: string) => new Date(iso).toLocaleDateString('pt-BR', { timeZone: 'America/Sao_Paulo' })

export default async function DoadoresRecorrentesPage({
  searchParams,
}: {
  searchParams: Promise<{ filtro?: string }>
}) {
  const { filtro } = await searchParams
  const soInterrompidos = filtro === 'interrompidos'
  const { doadores, mensaisSemFicha } = await getDoadoresRecorrentes()
  const interrompidos = doadores.filter((d) => d.interrompido).length
  const lista = soInterrompidos ? doadores.filter((d) => d.interrompido) : doadores

  return (
    <div className="px-4 py-6 md:px-14 md:py-10 max-w-[1000px]">
      <header className="mb-8">
        <div className="text-xs text-muted font-body tracking-[2px] uppercase mb-2">Clientes · Doadores recorrentes</div>
        <h1 className="font-display text-[28px] md:text-[40px] text-ink font-semibold tracking-[-1px] m-0 leading-[1.1]">
          Doadores recorrentes
        </h1>
        <p className="font-body text-muted text-sm mt-2 max-w-[600px]">
          Quem já fez doação mensal, com a data da última doação. Mais de {DIAS_PARA_INTERROMPIDO} dias sem doar aparece como interrompido.
        </p>
      </header>

      <nav aria-label="Filtro" className="flex flex-wrap gap-2 mb-6">
        <Link
          href="/clientes/recorrentes"
          aria-current={!soInterrompidos ? 'page' : undefined}
          className={`chip no-underline ${!soInterrompidos ? 'bg-ink text-bg border-ink' : 'bg-paper text-muted border-rule'}`}
        >
          Todos ({doadores.length})
        </Link>
        <Link
          href="/clientes/recorrentes?filtro=interrompidos"
          aria-current={soInterrompidos ? 'page' : undefined}
          className={`chip no-underline ${soInterrompidos ? 'bg-ink text-bg border-ink' : 'bg-paper text-muted border-rule'}`}
        >
          Só interrompidos ({interrompidos})
        </Link>
      </nav>

      {lista.length === 0 ? (
        <div className="bg-paper border border-rule rounded-[16px] p-10 text-center font-body text-sm text-muted">
          {soInterrompidos ? 'Nenhum doador recorrente interrompido.' : 'Nenhuma pessoa com doação mensal.'}
        </div>
      ) : (
        <ul data-testid="doadores-recorrentes" className="m-0 p-0 list-none bg-paper border border-rule rounded-[16px] overflow-hidden">
          {lista.map((d) => (
            <li
              key={d.id}
              data-testid="doador-recorrente"
              className="px-6 py-4 border-b border-rule last:border-0 flex flex-wrap items-center justify-between gap-3"
            >
              <div>
                <div className="font-body text-sm text-ink font-medium">{d.name}</div>
                <div className="font-body text-xs text-muted mt-0.5">
                  R$ {formatBRL(d.valorMensal)} por mês · última doação em {dataCurta(d.ultimaDoacao)}
                </div>
              </div>
              {d.interrompido ? (
                <span className="text-xs font-body px-2 py-1 rounded-full" style={{ backgroundColor: '#F8DCD2', color: '#D87560' }}>
                  interrompida há {d.diasSemDoar} dias
                </span>
              ) : (
                <span className="text-xs font-body px-2 py-1 rounded-full" style={{ backgroundColor: '#DCEBE0', color: '#2E5C3E' }}>
                  em dia
                </span>
              )}
            </li>
          ))}
        </ul>
      )}

      {mensaisSemFicha > 0 && (
        <p className="font-body text-xs text-muted mt-4">
          {mensaisSemFicha === 1 ? '1 doação mensal está' : `${mensaisSemFicha} doações mensais estão`} sem ficha e não aparecem aqui. Ligue a doação a uma pessoa em Doações · Sem ficha.
        </p>
      )}
    </div>
  )
}
```

import { entrar, valorUnico } from './apoio'

// US-20 · Acompanhamento de doadores recorrentes.
test.describe('Fumaça: doadores recorrentes', () => {

    await page.getByRole('link', { name: /Só interrompidos/ }).click()
    await expect(page).toHaveURL(/filtro=interrompidos/)
    await expect(page.getByTestId('doador-recorrente').filter({ hasText: 'Roberta Lima' })).toBeVisible()
    await expect(page.getByText(/em dia/)).toHaveCount(0)

  test('quem doou este mês aparece em dia e sai do filtro de interrompidos', async ({ page }) => {
    const valor = valorUnico(40)
    await entrar(page)

    await test.step('registrar uma doação mensal para a Helena Vasconcelos', async () => {
      await page.goto('/doacoes/dinheiro/nova')
      await page.getByLabel('Buscar pessoa').fill('helena')
      await page.getByTestId('resultado-da-busca').getByText('Helena Vasconcelos').click()
      await page.locator('input[name="amount"]').fill(valor.numero.toFixed(2))
      await page.getByRole('button', { name: 'Mensal' }).click()

      await expect(page).toHaveURL(/\/doacoes\/dinheiro$/)
    })

    await page.goto('/clientes/recorrentes')
    const helena = page.getByTestId('doador-recorrente').filter({ hasText: 'Helena Vasconcelos' })
    await expect(helena.getByText('em dia')).toBeVisible()

    await page.goto('/clientes/recorrentes?filtro=interrompidos')
    await expect(page.getByTestId('doador-recorrente').filter({ hasText: 'Helena Vasconcelos' })).toHaveCount(0)
