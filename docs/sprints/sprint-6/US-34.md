# US-34 · Confirmação de doação em dinheiro de valor muito alto (1 SP)

> Como caixa do brechó, eu quero que o sistema peça confirmação quando eu digitar um valor muito alto numa doação em dinheiro, para que um zero a mais não vire uma receita que não existiu.

**Tipo:** user story · **Implementa:** Alissa · **Revisa:** Bibiana · **Branch:** `us-34-valor-muito-alto` · **Depende de:** limite confirmado pela coordenação (proposta: R$ 1.000; enquanto não vier, vale a proposta) · **Publica:** quarta 04/11, à noite

## Critérios de aceitação

- [ ] Acima do limite combinado com a coordenação, o formulário de doação em dinheiro mostra o valor formatado e pede confirmação antes de registrar
- [ ] Sem a confirmação, a doação não é registrada; abaixo do limite, nada muda
- [ ] Teste de fumaça com valor acima e abaixo do limite

## O que muda para quem usa

Item anotado na Sprint 4, sem cartão até 30/10. Em Doações · Dinheiro · Nova doação, quem digita mais que R$ 1.000,00 vê, no lugar do clique direto, um quadro com o valor formatado em reais ("R$ 10.000,00") e dois botões: "Sim, registrar" e "Corrigir o valor". Até R$ 1.000,00, o formulário funciona como hoje.

## Decisões

- **Limite numa constante só** (`lib/valor-alto.ts`), usada pelo formulário e pelo servidor. Se a coordenação escolher outro valor, muda uma linha.
- **A conferência vale também no servidor.** A Server Action recusa valor acima do limite sem a marca de confirmação, para um formulário antigo aberto numa aba não passar direto.
- **"Acima do limite"** é maior que R$ 1.000,00. Exatamente R$ 1.000,00 não pede confirmação.

## 5. Teste: `tests/fumaca/valor-muito-alto.spec.ts` (arquivo novo)

```ts
import { expect, test } from '@playwright/test'
import { doacaoSemFicha, entrar, valorUnico } from './apoio'

// US-34 · Confirmação de doação em dinheiro de valor muito alto (limite: R$ 1.000).
test.describe('Fumaça: doação de valor muito alto', () => {
  test('abaixo do limite, registra direto', async ({ page }) => {
    const doador = `TESTE US-34 abaixo ${Date.now()}`
    const valor = valorUnico(500)
    await entrar(page)
    await page.goto('/doacoes/dinheiro/nova')
    await doacaoSemFicha(page, doador)
    await page.locator('input[name="amount"]').fill(valor.numero.toFixed(2))
    await page.getByRole('button', { name: 'Registrar doação' }).click()
    await expect(page).toHaveURL(/\/doacoes\/dinheiro$/)
    await expect(page.getByRole('row').filter({ hasText: doador })).toBeVisible()
  })

  test('acima do limite, pede confirmação; sem confirmar, não registra', async ({ page }) => {
    const doador = `TESTE US-34 acima ${Date.now()}`
    await entrar(page)
    await page.goto('/doacoes/dinheiro/nova')
    await doacaoSemFicha(page, doador)
    await page.locator('input[name="amount"]').fill('10000')
    await page.getByRole('button', { name: 'Registrar doação' }).click()

    const confirmacao = page.getByTestId('confirmacao-valor-alto')
    await expect(confirmacao).toContainText('R$ 10.000,00')
    await expect(page).toHaveURL(/\/doacoes\/dinheiro\/nova$/)

    await confirmacao.getByRole('button', { name: 'Corrigir o valor' }).click()
    await expect(confirmacao).toHaveCount(0)

    await page.goto('/doacoes/dinheiro')
    await expect(page.getByRole('row').filter({ hasText: doador })).toHaveCount(0)
  })

  test('acima do limite, com confirmação, registra', async ({ page }) => {
    const doador = `TESTE US-34 confirmada ${Date.now()}`
    const valor = valorUnico(1500)
    await entrar(page)
    await page.goto('/doacoes/dinheiro/nova')
    await doacaoSemFicha(page, doador)
    await page.locator('input[name="amount"]').fill(valor.numero.toFixed(2))
    await page.getByRole('button', { name: 'Registrar doação' }).click()
    await page.getByTestId('confirmacao-valor-alto').getByRole('button', { name: 'Sim, registrar' }).click()
    await expect(page).toHaveURL(/\/doacoes\/dinheiro$/)
    await expect(page.getByRole('row').filter({ hasText: doador }).getByText(valor.exibido)).toBeVisible()
  })
})
```

## Fora desta story

- Confirmação na venda: não pedida. O valor da venda é a soma de peças, e o atalho já preenche o valor.
- Limite diferente por perfil: não pedido.
- Limite cadastrado pela coordenação numa tela: se o valor mudar com frequência, story nova no padrão do valor do atendimento (US-19).
