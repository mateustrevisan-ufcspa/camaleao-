# US-16 · Recibo de doação (3 SP)

> Como apoiadora do Instituto, eu quero receber um recibo da doação que fiz, para que eu tenha o documento para meus registros e prestação de contas.

**Tipo:** user story · **Implementa:** Mateus · **Revisa:** Laís · **Branch:** `us-16-recibo-de-doacao` · **Depende de:** dados do Instituto para o recibo (sem eles, só o nome); traz a `main` com a US-04a e a US-27 antes do merge (mesma lista de itens) · **Publica:** quinta 05/11, à noite

## Critérios de aceitação

- [ ] Nas listas de Doações · Dinheiro e Doações · Itens e no histórico da ficha, "Recibo" abre uma página pronta para imprimir ou salvar em PDF
- [ ] O recibo traz os dados do Instituto, o nome de quem doou, o tipo de doação e a data; na doação em dinheiro, valor, forma de pagamento e os atendimentos que ela ajuda a custear (US-19); na de item, categoria e quantidade, sem valor
- [ ] O recibo indica o evento ou a campanha quando a doação estiver vinculada (US-12 e US-13)
- [ ] Doação sem ficha tem recibo com o nome informado na doação
- [ ] Quem abre o recibo segue a matriz: coordenação em qualquer doação; balcão nas lançadas hoje, e a voluntária só nas de item (US-28)
- [ ] Teste de fumaça (recibo com valor e atendimentos) e teste de acesso

## O que já existe

A US-16 está no Product Backlog desde o começo. A US-19 deixou para ela o critério "atendimentos no recibo", com a mesma conversão: `atendimentos(valor, valorDoAtendimento)` e `textoDeAtendimentos` em `lib/atendimentos.ts`, e `getValorDoAtendimento()` em `lib/store.ts` (a equipe lê o valor).

A doação em dinheiro tem nome, valor, "origem" (PIX, Dinheiro, Site, Transferência, Outro: é a forma de pagamento), evento ou campanha (`donations_cash_view`). A doação de item tem nome, categoria, quantidade e peso; depois da US-27, também as três contagens da triagem.

## Decisões

- **Uma página de recibo, fora do menu** (`/recibo/dinheiro/ID` e `/recibo/itens/ID`), sem a barra lateral, com estilo de impressão. "Imprimir ou salvar em PDF" chama a impressão do navegador, que já oferece "Salvar como PDF". Sem gerar PDF no servidor.
- **Quem pode abrir é decidido pelo banco.** A página lê a doação pela API: se o perfil não enxerga a doação (balcão numa doação de ontem, voluntária numa doação em dinheiro depois da US-28, doação excluída pela US-04a), a página mostra "Recibo não encontrado". Nenhuma regra nova.
- **Dados do Instituto num arquivo** (`lib/instituto.ts`). Campo vazio não aparece no recibo. Enquanto a coordenação não mandar CNPJ, endereço e quem assina, o recibo sai só com o nome.
- **Número do recibo:** os 8 primeiros caracteres do id da doação, em maiúsculas. Não é numeração fiscal; se o Instituto precisar de numeração sequencial, story nova.
- **Sem envio automático por mensagem:** é da US-21.

```ts
// ── RECIBO DE DOAÇÃO (US-16) ──
// Lê pela API: quem não enxerga a doação (balcão em doação de outro dia, voluntária
// em doação em dinheiro, doação excluída) recebe null.

const numeroDoRecibo = (id: string) => id.slice(0, 8).toUpperCase()

export async function getRecibo(tipo: 'dinheiro' | 'itens', id: string): Promise<Recibo | null> {
  const supabase = await createClient()

  if (tipo === 'dinheiro') {
    const { data: d, error } = await supabase
      .from('donations_cash_view')
      .select('id, donated_at, donor_name, amount, origin, event_name, campaign_name')
      .eq('id', id)
      .maybeSingle()
    if (error) throw new Error(error.message)
    if (!d) return null
    const valor = Number(d.amount)
    const valorDoAtendimento = await getValorDoAtendimento()
    return {
      tipo,
      numero: numeroDoRecibo(d.id as string),
      data: d.donated_at as string,
      doador: d.donor_name as string,
      valor,
      forma: (d.origin as string) || null,
      atendimentos: atendimentos(valor, valorDoAtendimento),
      valorDoAtendimento,
      categoria: null,
      quantidade: null,
      vinculo: d.event_name ? `Evento: ${d.event_name}` : d.campaign_name ? `Campanha: ${d.campaign_name}` : null,
    }
  }

  const { data: d, error } = await supabase
    .from('donations_items')
    .select('id, donated_at, donor_name, category_name, quantity, weight_kg')
    .eq('id', id)
    .maybeSingle()
  if (error) throw new Error(error.message)
  if (!d) return null
  const partes = [
    d.quantity ? `${d.quantity} ${d.quantity === 1 ? 'peça' : 'peças'}` : '',
    d.weight_kg ? `${Number(d.weight_kg).toLocaleString('pt-BR')} kg` : '',
  ].filter(Boolean)
  return {
    tipo,
    numero: numeroDoRecibo(d.id as string),
    data: d.donated_at as string,
    doador: d.donor_name as string,
    valor: null,
    forma: null,
    atendimentos: null,
    valorDoAtendimento: null,
    categoria: (d.category_name as string) || 'itens',
    quantidade: partes.length > 0 ? partes.join(' · ') : null,
    vinculo: null,
  }
}
```
