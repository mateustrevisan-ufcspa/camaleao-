# US-32 · Taxas de cartão cadastradas pela coordenação (5 SP)

> Como coordenadora do financeiro, eu quero cadastrar as taxas reais de cada maquininha, no crédito, no débito e no parcelado, para que o valor líquido das vendas seja o que de fato cai na conta do Instituto.

**Tipo:** user story · **Implementa:** Bibiana · **Revisa:** Mateus · **Branch:** `us-32-taxas-de-cartao` · **Depende de:** US-29 integrada (mesmo financeiro); respostas da Nílian sobre Pix na Sicredi, Stone, PIX TON e "outros cartões" (sem elas, vale o provisório abaixo) · **Publica:** quinta 05/11, à noite, último merge da noite

**Regra de corte:** é a última story da fila da Bibiana. Sem aprovação na quinta às 18h, volta ao topo do backlog e a sprint fecha com 35 SP.

## Critérios de aceitação

- [ ] A coordenação cadastra e altera as taxas por maquininha, forma (Pix, débito, crédito à vista, crédito parcelado) e, no débito da PagBank, bandeira; vê quem alterou e quando; o balcão não altera
- [ ] A venda nova usa a taxa em vigor para a maquininha, a forma, à vista ou parcelado (taxa única para qualquer número de parcelas) e a bandeira
- [ ] A tabela começa com as taxas informadas pela Nílian em 30/10 (Sicredi e PagBank, na descrição do cartão)
- [ ] No débito da PagBank, o formulário de venda pede a bandeira (Visa ou Master, ou outra); nas outras combinações o campo não aparece
- [ ] As vendas antigas mantêm o valor líquido gravado

## O que já existe

Dúvida da Nílian em 29/10: "as taxas dos cartões já estarão cadastradas?". Hoje, em `actions/sales.ts`:

```ts
function calcNetAmount(amount: number, paymentMethod: string): number {
  if (paymentMethod === 'credit') return parseFloat((amount * 0.98).toFixed(2))
  if (paymentMethod === 'debit')  return parseFloat((amount * 0.982).toFixed(2))
  return amount
}
```

2% no crédito e 1,8% no débito, iguais para todo banco e sem considerar parcelas; Pix sem taxa. O líquido é gravado em cada venda (`sales.net_amount`), pela função `register_sale`.

Bancos do seed (`banks`, tipo `pix` ou `card`): `PIX TON`, `PIX SICREDI`, `SICREDI`, `PagSeguro` e `Stone`. **O sistema não tem tela de Configurações:** os acertos de banco desta story vão na migração (desvio do cartão, que falava em Configurações; corrigido no Trello em 30/10).

## Decisões

- **Uma linha por alteração**, no padrão do valor do atendimento (US-19): alterar uma taxa é cadastrar a mesma combinação de novo; a taxa em vigor é a linha mais recente. Quem e quando vêm do banco, por gatilho. Ninguém altera nem apaga uma linha.
- **Chave da taxa:** maquininha (banco), forma (`pix`, `debit`, `credit`), parcelado (só no crédito) e bandeira (só no débito, e só na PagBank, por enquanto). Taxa em porcentagem, de 0 a 20.
- **PagSeguro passa a se chamar PagBank,** e entra o banco `PIX PagBank` (tipo `pix`), na migração. As vendas antigas no PagSeguro passam a aparecer como PagBank, porque a venda guarda o id do banco.
- **Bandeira** guardada na venda (`sales.card_brand`), só no débito da PagBank: `visa_master` ou `outras`.
- **Sem taxa cadastrada, o líquido fica vazio** (`net_amount` nulo) e o financeiro mostra "taxa não cadastrada". Dinheiro não tem taxa: o líquido é o bruto. A taxa que a coordenação cadastrar depois não muda a venda já registrada.
- **Provisório, até a Nílian responder:** Pix na Sicredi (`PIX SICREDI`), `PIX TON` e `Stone` começam sem taxa. Se ela disser que o Pix na Sicredi não tem taxa, a coordenação cadastra 0% na tela (ou entra uma linha com 0 na migração, se a resposta vier antes do merge). Se Stone e PIX TON não forem mais usados, a migração ganha `update public.banks set active = false where name in ('Stone', 'PIX TON');`. "Outros cartões" do débito aparece como "Outras bandeiras".
- **Vendas antigas não mudam:** a migração não recalcula nada.

```ts
// US-32 · Taxas das maquininhas.

export type FormaComTaxa = 'pix' | 'debit' | 'credit'
export type Bandeira = 'visa_master' | 'outras'

export const BANDEIRAS: { valor: Bandeira; rotulo: string }[] = [
  { valor: 'visa_master', rotulo: 'Visa ou Master' },
  { valor: 'outras', rotulo: 'Outras bandeiras' },
]

// Maquininhas em que a taxa do débito depende da bandeira (Nílian, 30/10).
export const BANCOS_COM_BANDEIRA_NO_DEBITO = ['PagBank']

export function pedeBandeira(banco: string | null | undefined, forma: string): boolean {
  return forma === 'debit' && !!banco && BANCOS_COM_BANDEIRA_NO_DEBITO.includes(banco)
}

// Líquido da venda: dinheiro não tem taxa; sem taxa cadastrada, null
// (o financeiro mostra "taxa não cadastrada").
export function valorLiquido(bruto: number, forma: string, taxa: number | null): number | null {
  if (forma === 'cash') return bruto
  if (taxa === null) return null
  return Math.round(bruto * (1 - taxa / 100) * 100) / 100
}

export function rotuloDaCombinacao(t: { forma: string; parcelado: boolean; bandeira: string | null }): string {
  if (t.forma === 'pix') return 'Pix'
  if (t.forma === 'debit') {
    const bandeira = BANDEIRAS.find((b) => b.valor === t.bandeira)?.rotulo
    return bandeira ? `Débito, ${bandeira}` : 'Débito'
  }
  return t.parcelado ? 'Crédito parcelado' : 'Crédito à vista'
}

// "1,88%"
export const textoDaTaxa = (taxa: number) => `${taxa.toLocaleString('pt-BR', { minimumFractionDigits: 2, maximumFractionDigits: 2 })}%`
```

```ts
// ── TAXAS DAS MAQUININHAS (US-32) ──
// A equipe lê (o caixa precisa da taxa ao registrar a venda); só a coordenação cadastra.

export async function getTaxaEmVigor(
  banco: string,
  forma: string,
  parcelado: boolean,
  bandeira: 'visa_master' | 'outras' | null
): Promise<number | null> {
  const supabase = await createClient()
  let consulta = supabase
    .from('taxas_em_vigor')
    .select('taxa')
    .eq('bank_name', banco)
    .eq('forma', forma)
    .eq('parcelado', parcelado)
  consulta = bandeira ? consulta.eq('bandeira', bandeira) : consulta.is('bandeira', null)
  const { data, error } = await consulta.maybeSingle()
  if (error) throw new Error(error.message)
  return data ? Number(data.taxa) : null
}

export async function getTaxasEmVigor(): Promise<TaxaEmVigor[]> {
  const supabase = await createClient()
  const { data, error } = await supabase
    .from('taxas_em_vigor')
    .select('id, bank_id, bank_name, forma, parcelado, bandeira, taxa, definido_em')
    .order('bank_name')
    .order('forma')
    .order('parcelado')
  if (error) throw new Error(error.message)
  return ((data ?? []) as TaxaEmVigor[]).map((t) => ({ ...t, taxa: Number(t.taxa) }))
}
```

```ts
'use server'

import { revalidatePath } from 'next/cache'
import { addTaxaDeCartao, getBanks } from '@/lib/store'
import { pedeBandeira } from '@/lib/taxas'
import { parseMoney } from '@/lib/utils'

const FORMAS = {
  pix: { forma: 'pix', parcelado: false, tipoDoBanco: 'pix' },
  debit: { forma: 'debit', parcelado: false, tipoDoBanco: 'card' },
  credit_avista: { forma: 'credit', parcelado: false, tipoDoBanco: 'card' },
  credit_parcelado: { forma: 'credit', parcelado: true, tipoDoBanco: 'card' },
} as const

// US-32 · Cadastra a taxa de uma combinação. Alterar é cadastrar de novo; a mais recente vale.
export async function definirTaxaDeCartao(fd: FormData): Promise<{ error: string } | void> {
  const bankId = ((fd.get('bank_id') as string) || '').trim()
  const escolha = FORMAS[((fd.get('forma') as string) || '') as keyof typeof FORMAS]
  const bandeiraDigitada = fd.get('bandeira')
  const digitada = ((fd.get('taxa') as string) || '').trim()
  const taxa = digitada ? parseMoney(digitada) : NaN

  if (!escolha) return { error: 'Escolha a forma de pagamento.' }
  if (!Number.isFinite(taxa) || taxa < 0 || taxa > 20 || digitada.includes('-')) {
    return { error: 'Informe a taxa em porcentagem, de 0 a 20 (por exemplo, 1,88).' }
  }

  try {
    const banco = (await getBanks()).find((b) => b.id === bankId)
    if (!banco) return { error: 'Escolha uma maquininha da lista.' }
    if (banco.type !== escolha.tipoDoBanco) {
      return { error: escolha.forma === 'pix' ? 'Pix só em banco de Pix.' : 'Débito e crédito só em maquininha de cartão.' }
    }
    const comBandeira = pedeBandeira(banco.name, escolha.forma)
    const bandeira = comBandeira && (bandeiraDigitada === 'visa_master' || bandeiraDigitada === 'outras') ? bandeiraDigitada : null
    if (comBandeira && !bandeira) return { error: 'No débito desta maquininha, escolha a bandeira.' }

    await addTaxaDeCartao({ bank_id: banco.id, forma: escolha.forma, parcelado: escolha.parcelado, bandeira, taxa: Math.round(taxa * 100) / 100 })
  } catch (e) {
    console.error('definirTaxaDeCartao error:', e)
    return { error: 'Não foi possível salvar a taxa. Só a coordenação altera.' }
  }
  revalidatePath('/relatorios/taxas')
}
```
