# US-27 · Contagem da triagem do item doado (8 SP)

> Como voluntária do brechó, eu quero registrar a entrada da sacola e, depois da triagem, quantas peças foram aproveitadas, redoadas e descartadas, para que o destino de cada doação fique anotado do jeito que o Instituto já trabalha, e não dependa da memória de quem recebeu.

**Tipo:** user story · **Implementa:** Alissa · **Revisa:** Bibiana · **Branch:** `us-27-contagem-da-triagem` · **Depende de:** US-04a integrada (mesmo formulário); resposta da Tamara sobre as tampinhas (sem ela, vale o provisório abaixo) · **Publica:** quinta 05/11, à noite, primeiro merge da noite

## Critérios de aceitação

- [ ] No formulário de doação de item, Quantidade, Estado e Destino dão lugar a Aproveitadas, Redoadas e Descarte (inteiros de 0 a 300), que podem ficar vazios na entrada
- [ ] O campo Peso sai do formulário de item (para a categoria Tampinha, segue a resposta da Tamara)
- [ ] Doação sem as três contagens aparece como "Triagem pendente"; a voluntária registra a triagem também em doação de dias anteriores, alterando só as contagens
- [ ] A edição da US-04a usa os campos novos
- [ ] Relatório consolidado e exportação trazem as somas de Aproveitadas, Redoadas e Descarte no lugar de Estado e Destino
- [ ] Testes de fumaça (entrada sem contagem, triagem depois, somas no relatório) e de acesso (balcão registra a triagem de ontem e não altera os outros campos) passam

## Como o Instituto trabalha

Pelo relato da Tamara (29/10): a voluntária não abre as sacolas. Pergunta ao doador o que é, anota a data, o nome e o telefone, e grampeia na sacola um papel com a data e o nome. A triagem devolve o papel com três contagens: **Aproveitadas** (vão para a venda), **Redoadas** (outras entidades) e **Descarte**, até 300 peças cada. Hoje isso vai para três planilhas do Google: roupas, tampinhas e diversas (livros, utensílios, cabelos, perucas e outros).

Ou seja, a doação tem dois momentos: **a entrada**, no dia em que chega, e **a triagem**, dias depois.

## O que muda para quem usa

- **Nova doação de item:** some Quantidade, Peso, Estado e Destino. Entram Aproveitadas, Redoadas e Descarte, que podem ficar vazios.
- **Tampinha** (provisório, até a Tamara responder): continua como hoje, com Quantidade e Peso e sem triagem. Se ela disser que tampinha também é contada na triagem, basta tirar `'tampinha'` de `SEM_TRIAGEM` (Parte C) e da função `triagens_pendentes` (Parte A).
- **Doações · Itens** ganha a seção **Triagem pendente**, com as doações sem contagem de qualquer dia, inclusive de dias anteriores, e um formulário de três números por linha. Quem é do balcão registra ali a triagem de uma doação de outro dia; o resto da doação não muda.
- **Na lista**, a doação sem contagem mostra a etiqueta "Triagem pendente"; a contada mostra "12 aproveitadas · 3 redoadas · 1 descarte".
- **Relatório consolidado e planilha:** colunas Aproveitadas, Redoadas e Descarte no lugar de Estado e Destino.

## Decisões

- **As três contagens vão juntas ou nenhuma.** Na entrada, todas vazias quer dizer "triagem pendente". Se alguém preencher uma e deixar outra vazia, a vazia vale zero. O banco garante: ou as três têm valor, ou nenhuma.
- **Pendente** é doação sem as três contagens, de categoria que tem triagem (todas menos tampinha), **sem quantidade antiga e sem peso.** As doações de antes desta story que têm quantidade continuam como estão, sem aparecer como pendentes.
- **Quem e quando da triagem vêm do banco** (`triado_em`, `triado_por`), por gatilho, como o valor do atendimento da US-19.
- **Triagem de outro dia é uma função do banco** (`registrar_triagem`, `security definer`), porque o balcão só enxerga e só altera o que foi lançado hoje (US-23 e US-04a). A função altera só as três contagens, e só de doação que ainda está pendente; a coordenação pode refazer.
- **A lista de pendentes de outros dias também é uma função** (`triagens_pendentes`), que devolve só o necessário para achar o papel da sacola: data, nome, categoria e observação. Sem telefone.
- **Estado e Destino continuam no banco** para as doações antigas. O registro original da ficha mostra os dois só quando a doação tem.

```sql
-- US-27 · Contagem da triagem do item doado
-- A doação de item tem dois momentos: a entrada e, dias depois, a triagem, com
-- quantas peças foram aproveitadas, redoadas e descartadas (até 300 cada).

-- ─────────────────────────────────────────
-- 1. As três contagens e quem e quando registrou a triagem.
--    Ou as três têm valor, ou nenhuma (triagem pendente).
-- ─────────────────────────────────────────

alter table public.donations_items
  add column if not exists aproveitadas int check (aproveitadas between 0 and 300),
  add column if not exists redoadas     int check (redoadas between 0 and 300),
  add column if not exists descarte     int check (descarte between 0 and 300),
  add column if not exists triado_em    timestamptz,
  add column if not exists triado_por   uuid references public.users(id) on delete set null;

alter table public.donations_items
  add constraint donations_items_triagem_completa check (
    (aproveitadas is null and redoadas is null and descarte is null)
    or (aproveitadas is not null and redoadas is not null and descarte is not null)
  );

-- ─────────────────────────────────────────
-- 2. Quem e quando da triagem vêm do banco. Contagem que não mudou mantém o
--    carimbo antigo (exclusão, mesclagem e correção de outros campos).
-- ─────────────────────────────────────────

create or replace function public.carimbar_triagem()
returns trigger
language plpgsql
set search_path = ''
as $$
begin
  if tg_op = 'INSERT' then
    new.triado_em  := case when new.aproveitadas is null then null else now() end;
    new.triado_por := case when new.aproveitadas is null then null else auth.uid() end;
  elsif (new.aproveitadas, new.redoadas, new.descarte)
        is distinct from (old.aproveitadas, old.redoadas, old.descarte) then
    new.triado_em  := case when new.aproveitadas is null then null else now() end;
    new.triado_por := case when new.aproveitadas is null then null else auth.uid() end;
  else
    new.triado_em  := old.triado_em;
    new.triado_por := old.triado_por;
  end if;
  return new;
end;
$$;

create trigger carimbo_da_triagem
  before insert or update on public.donations_items
  for each row execute function public.carimbar_triagem();

-- ─────────────────────────────────────────
-- 3. A edição pela API (US-04a) também altera as três contagens, nas doações
--    que a política deixa alterar (balcão: as lançadas hoje).
-- ─────────────────────────────────────────

grant update (aproveitadas, redoadas, descarte) on public.donations_items to authenticated;

-- ─────────────────────────────────────────
-- 4. Triagem de doação de outro dia. security definer: o balcão não enxerga
--    nem altera a doação de ontem pela API. Altera só as três contagens, só de
--    doação não excluída e ainda pendente; a coordenação pode refazer.
-- ─────────────────────────────────────────

create or replace function public.registrar_triagem(
  p_id uuid,
  p_aproveitadas int,
  p_redoadas int,
  p_descarte int
)
returns void
language plpgsql
security definer
set search_path = ''
as $$
begin
  if not public.eh_equipe() then
    raise exception 'sem permissão para registrar triagem' using errcode = '42501';
  end if;
  if p_aproveitadas is null or p_redoadas is null or p_descarte is null then
    raise exception 'informe as três contagens' using errcode = '22023';
  end if;

  update public.donations_items d
     set aproveitadas = p_aproveitadas,
         redoadas     = p_redoadas,
         descarte     = p_descarte
   where d.id = p_id
     and d.deleted_at is null
     and (d.aproveitadas is null or public.eh_coordenacao());

  if not found then
    raise exception 'doação não encontrada ou com triagem já registrada' using errcode = 'P0002';
  end if;
end;
$$;

revoke execute on function public.registrar_triagem(uuid, int, int, int) from public, anon;
grant execute on function public.registrar_triagem(uuid, int, int, int) to authenticated;

-- ─────────────────────────────────────────
-- 5. Doações com triagem pendente, de qualquer dia, para o balcão achar a
--    sacola. Só data, nome, categoria e observação; sem telefone. Tampinha não
--    tem triagem; doação antiga com quantidade ou peso também não fica pendente.
-- ─────────────────────────────────────────

create or replace function public.triagens_pendentes()
returns table (id uuid, donated_at timestamptz, donor_name text, category_name text, notes text)
language sql
stable
security definer
set search_path = ''
as $$
  select d.id, d.donated_at, d.donor_name, d.category_name, d.notes
    from public.donations_items d
   where public.eh_equipe()
     and d.deleted_at is null
     and d.aproveitadas is null
     and d.quantity is null
     and d.weight_kg is null
     and lower(coalesce(d.category_name, '')) <> 'tampinha'
   order by d.donated_at, d.created_at
   limit 200
$$;

revoke execute on function public.triagens_pendentes() from public, anon;
grant execute on function public.triagens_pendentes() to authenticated;
```

## Parte C · `lib/triagem.ts` (arquivo novo)

Regras da triagem em um lugar só, para o servidor e o navegador.

```ts
// US-27 · Contagem da triagem do item doado.

// Categorias sem triagem: só se registra que chegou (quantidade e peso). Provisório
// até a resposta da Tamara; se a tampinha passar a ter triagem, tire daqui e da
// função triagens_pendentes (migração 20261103090000).
export const SEM_TRIAGEM = ['tampinha']

export const MAXIMO_DA_CONTAGEM = 300

export interface Contagens {
  aproveitadas: number
  redoadas: number
  descarte: number
}

export function semTriagem(categoria: string | null | undefined): boolean {
  return SEM_TRIAGEM.includes((categoria ?? '').trim().toLowerCase())
}

type ItemParaTriagem = {
  category_name: string
  aproveitadas: number | null
  redoadas: number | null
  descarte: number | null
  quantity: number | null
  weight_kg: number | null
}

// A mesma regra da função triagens_pendentes, para a lista do dia.
export function triagemPendente(d: ItemParaTriagem): boolean {
  return !semTriagem(d.category_name) && d.aproveitadas === null && d.quantity === null && d.weight_kg === null
}

// Peças da doação: as três contagens somadas; sem triagem, a quantidade antiga.
export function pecasDaDoacao(d: ItemParaTriagem): number {
  if (d.aproveitadas !== null) return d.aproveitadas + (d.redoadas ?? 0) + (d.descarte ?? 0)
  return d.quantity ?? 0
}

// "12 aproveitadas · 3 redoadas · 1 descarte"
export function textoDaTriagem(c: { aproveitadas: number | null; redoadas: number | null; descarte: number | null }): string {
  return `${c.aproveitadas ?? 0} aproveitadas · ${c.redoadas ?? 0} redoadas · ${c.descarte ?? 0} descarte`
}

// Lê as três contagens de um formulário. Todas vazias: null (triagem pendente).
// Alguma preenchida: as vazias valem zero.
export function lerContagens(fd: FormData): { erro: string } | { contagens: Contagens | null } {
  const bruto = (['aproveitadas', 'redoadas', 'descarte'] as const).map((campo) => ((fd.get(campo) as string) || '').trim())
  if (bruto.every((v) => v === '')) return { contagens: null }

  const numeros = bruto.map((v) => (v === '' ? 0 : Number(v)))
  if (numeros.some((n) => !Number.isInteger(n) || n < 0 || n > MAXIMO_DA_CONTAGEM)) {
    return { erro: `Cada contagem precisa ser um número inteiro de 0 a ${MAXIMO_DA_CONTAGEM}.` }
  }
  const [aproveitadas, redoadas, descarte] = numeros
  return { contagens: { aproveitadas, redoadas, descarte } }
}
```

const dataBR = (iso: string) =>

// US-27 · Triagem de doação de outro dia, conferida pela API.
import { test, expect } from '@playwright/test'
import type { SupabaseClient } from '@supabase/supabase-js'
import { COORDENACAO, VOLUNTARIA, entrarNaApi, recusado } from './apoio'

const MARCA = 'TESTE US-27'

let coordenacao: SupabaseClient
let voluntaria: SupabaseClient
let voluntariaId: string
let deAnteontemId: string

test.describe.configure({ mode: 'serial' })

test.beforeAll(async () => {
  ;({ api: coordenacao } = await entrarNaApi(COORDENACAO))
  ;({ api: voluntaria, id: voluntariaId } = await entrarNaApi(VOLUNTARIA))

  const antes = new Date(Date.now() - 2 * 24 * 60 * 60 * 1000).toISOString()
  const r = await coordenacao
    .from('donations_items')
    .insert({ donor_name: MARCA, category_name: 'roupa', notes: 'sacola azul', donated_at: antes, created_at: antes })
    .select('id')
    .single()
  if (r.error) throw new Error(`Não criou a doação antiga: ${r.error.message}`)
  deAnteontemId = r.data.id
})

test.afterAll(async () => {
  if (coordenacao) await coordenacao.from('donations_items').delete().eq('donor_name', MARCA)
})

test('a voluntária vê a doação de outro dia na triagem pendente, sem telefone', async () => {
  const r = await voluntaria.rpc('triagens_pendentes')
  expect(r.error).toBeNull()
  const linha = (r.data as { id: string; notes: string }[]).find((p) => p.id === deAnteontemId)
  expect(linha?.notes).toBe('sacola azul')
  expect(linha).not.toHaveProperty('donor_phone')
  // Pela API, a doação de outro dia continua fora do alcance dela.
  expect(recusado(await voluntaria.from('donations_items').select('id').eq('id', deAnteontemId))).toBe(true)
})

test('a voluntária registra a triagem e não altera os outros campos', async () => {
  expect(recusado(await voluntaria.from('donations_items').update({ notes: 'trocado' }).eq('id', deAnteontemId).select())).toBe(true)

  const r = await voluntaria.rpc('registrar_triagem', { p_id: deAnteontemId, p_aproveitadas: 12, p_redoadas: 3, p_descarte: 1 })
  expect(r.error).toBeNull()

  const { data } = await coordenacao
    .from('donations_items')
    .select('aproveitadas, redoadas, descarte, notes, triado_por, triado_em')
    .eq('id', deAnteontemId)
    .single()
  expect(data).toMatchObject({ aproveitadas: 12, redoadas: 3, descarte: 1, notes: 'sacola azul', triado_por: voluntariaId })
  expect(data!.triado_em).not.toBeNull()
})

test('a voluntária não refaz uma triagem já registrada; a coordenação refaz', async () => {
  expect((await voluntaria.rpc('registrar_triagem', { p_id: deAnteontemId, p_aproveitadas: 1, p_redoadas: 1, p_descarte: 1 })).error).not.toBeNull()
  expect((await coordenacao.rpc('registrar_triagem', { p_id: deAnteontemId, p_aproveitadas: 10, p_redoadas: 5, p_descarte: 1 })).error).toBeNull()
})

test('contagem fora de 0 a 300, ou só uma das três, é recusada', async () => {
  expect((await coordenacao.rpc('registrar_triagem', { p_id: deAnteontemId, p_aproveitadas: 301, p_redoadas: 0, p_descarte: 0 })).error).not.toBeNull()
  expect((await coordenacao.from('donations_items').update({ aproveitadas: 5, redoadas: null }).eq('id', deAnteontemId)).error).not.toBeNull()
})
