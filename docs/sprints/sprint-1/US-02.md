# US-02 · Testes de fumaça das rotas críticas (5 SP)

> Como integrante da equipe, eu quero que os fluxos de login, venda e doação sejam testados automaticamente, para que eu perceba uma quebra antes que ela chegue à entrega.

**Implementa:** Mateus · **Valida e revisa:** Laís · **Branch:** `us-02-testes-fumaca` · **Depende de:** US-01 (seed do usuário de teste)

## Critérios de aceitação

- [ ] Deve cobrir login, registro de venda e registro de doação
- [ ] Deve rodar por um único comando documentado no README
- [ ] Deve falhar de forma legível, apontando o passo que quebrou

## Decisões

- **Playwright**, porque os três fluxos passam por Server Actions e redirecionamentos: só um navegador de verdade exercita o caminho completo.
- **Banco local** (`supabase start`) com o usuário de `supabase/seed.sql`. Nada toca a produção, e `supabase db reset` limpa o que os testes criarem.
- **`test.step` em cada passo**, para o relatório de falha dizer em qual passo quebrou.

## 3. `tests/smoke/apoio.ts`

```ts
import { expect, type Page } from '@playwright/test'

// Padrões iguais ao usuário de supabase/seed.sql (banco local).
export const EMAIL = process.env.E2E_EMAIL || 'teste@camaleao.test'
export const SENHA = process.env.E2E_PASSWORD || 'teste-local-camaleao'

export async function entrar(page: Page) {
  await page.goto('/login')
  await page.locator('input[name="email"]').fill(EMAIL)
  await page.locator('input[name="password"]').fill(SENHA)
  await page.getByRole('button', { name: 'Entrar' }).click()
  await expect(page).toHaveURL(/\/brecho$/)
}
```

## 4. `tests/smoke/login.spec.ts`

```ts
import { test, expect } from '@playwright/test'
import { EMAIL, SENHA } from './apoio'

test('login recusa senha errada e aceita a correta', async ({ page }) => {
  await test.step('abre a tela de login', async () => {
    await page.goto('/login')
    await expect(page.locator('input[name="email"]')).toBeVisible()
  })

  await test.step('senha errada mostra mensagem de erro', async () => {
    await page.locator('input[name="email"]').fill(EMAIL)
    await page.locator('input[name="password"]').fill('senha-errada')
    await page.getByRole('button', { name: 'Entrar' }).click()
    await expect(page.getByText('E-mail ou senha incorretos.')).toBeVisible()
  })

  await test.step('senha correta leva ao brechó', async () => {
    await page.locator('input[name="password"]').fill(SENHA)
    await page.getByRole('button', { name: 'Entrar' }).click()
    await expect(page).toHaveURL(/\/brecho$/)
  })
})

test('rota protegida sem sessão volta para o login', async ({ page }) => {
  await page.goto('/brecho')
  await expect(page).toHaveURL(/\/login$/)
})
```

## 5. `tests/smoke/venda.spec.ts`

```ts
import { test, expect } from '@playwright/test'
import { entrar } from './apoio'

test('registra uma venda avulsa em dinheiro', async ({ page }) => {
  await test.step('entra no sistema', async () => {
    await entrar(page)
  })

  await test.step('abre o registro de venda', async () => {
    await page.goto('/brecho/nova-venda')
    await expect(page.getByRole('button', { name: 'Registrar venda' })).toBeVisible()
  })

  await test.step('marca cliente avulso', async () => {
    await page.getByRole('button', { name: 'Anônimo / avulso' }).click()
  })

  await test.step('preenche uma peça', async () => {
    await page.getByPlaceholder('Categoria (saia, blusa, vestido...)').first().fill('blusa')
    await page.getByPlaceholder('0,00').first().fill('25')
  })

  await test.step('escolhe pagamento em dinheiro', async () => {
    // o menu lateral também tem "Dinheiro" (doações); por isso a busca fica dentro do formulário
    await page.locator('form').getByText('Dinheiro', { exact: true }).click()
  })

  await test.step('registra e volta ao brechó', async () => {
    await page.getByRole('button', { name: 'Registrar venda' }).click()
    await expect(page).toHaveURL(/\/brecho$/)
  })
})
```

## 6. `tests/smoke/doacao.spec.ts`

```ts
import { test, expect } from '@playwright/test'
import { entrar } from './apoio'

test('registra uma doação em dinheiro', async ({ page }) => {
  await test.step('entra no sistema', async () => {
    await entrar(page)
  })

  await test.step('abre o registro de doação em dinheiro', async () => {
    await page.goto('/doacoes/dinheiro/nova')
    await expect(page.getByRole('button', { name: 'Registrar doação' })).toBeVisible()
  })

  await test.step('preenche doador, valor e origem', async () => {
    await page.getByPlaceholder('Nome completo (ou Anônimo)').fill('Teste de fumaça')
    await page.locator('input[name="amount"]').fill('10')
    await page.locator('select[name="origin"]').selectOption('PIX')
  })

  await test.step('registra e volta à lista de doações', async () => {
    await page.getByRole('button', { name: 'Registrar doação' }).click()
    await expect(page).toHaveURL(/\/doacoes\/dinheiro$/)
  })
})
```

Os seletores foram escritos a partir dos componentes atuais (`new-sale-form.tsx`, `new-donation-form.tsx`, `client-picker.tsx`, `donor-field.tsx`). Se algum não achar o elemento, o passo nomeado mostra onde; ajuste o seletor, não o teste.
